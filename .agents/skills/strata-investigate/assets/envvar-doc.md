# `ENV_NAME`

調査対象: Strata `main` の HEAD `<完全な commit SHA>`（`YYYY-MM-DD` 時点）。

## 役割

何を制御するか。どの実行経路で効くか。

## 値と判定

未設定・空文字・有効値・無効値・変換方法・境界の規則。条件分岐があるなら表にする。

| ビルド | unset | 設定時に有効になる値 | 設定時に無効になる値 |
|---|---|---|---|
| <build 例> | <既定> | <受理値と例> | <無効値と例> |

大文字小文字・空白・数値妥当性の検査有無もここで書く。

## 有効になる条件

OS / backend / build macro / サーバーモード / CLI オプション / モデル状態 / 他の環境変数などの条件と、
無効化・fallback・上書きされる経路。値が有効でも機能が使われない条件を必ず書く。

## 実行時の詳細

実際の処理の流れ、読み取り時期（起動時 / static cache / リクエストごと）、プロセス起動後の変更が反映されるか、
子プロセスへの継承・上書き、関連ログ。

## 根拠

`path/to/file.cpp:123-145` のように、各主張を支えるソース位置を近くに示す。
測定値を記載する場合は、資料の場所と測定条件（機種・OS・backend・モデル・量子化・設定・回数）も示す。
