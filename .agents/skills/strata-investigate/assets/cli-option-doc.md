# `<tool> <command> --option`

調査対象: Strata commit `<完全な commit SHA>`（`YYYY-MM-DD` 時点）。

| 項目 | 内容 |
| --- | --- |
| ツール ID | `<tool-id>` |
| コマンド | `<strata subcommand>` |
| オプション | `--option` |
| 別名 | `-o`（なければ「なし」） |
| 値 | 値を取るか、形式・型・範囲 |

## 役割

このオプションが何を制御するか、どの利用者・実行経路で役立つか。

## 使い方

正確なコマンド例と、必要なら他オプションや位置引数を含む最小例。例がコード上の正式な構文と一致すること。
機密値・破壊的な出力先・既存ファイル上書きの例は避け、危険な副作用が主目的なら安全なサンプル値で説明する。

## 値と既定値

値の有無・形式・受理範囲、未指定時の既定値、空値・無効値・重複指定時の挙動。

## 実行時の動作

parser の受理から実際の効果まで。設定ファイル・環境変数・他オプションとの優先順位や相互作用も含める。
環境変数との相互作用は `docs/envvars/<NAME>.md` へリンクし、全仕様を複製しない。

## 適用条件と副作用

OS / backend / build / モデル状態などの条件、無視・拒否・fallback 条件、
ファイル・ネットワーク・プロセス・server/GPU 等への影響。

## 出力とエラー

確認できた stdout/stderr、警告・エラー、終了コード、失敗条件。該当しなければ節を省略する。

## 根拠

主張の近くに `path/to/file.cpp:123` のようなソース位置を示す。
parser 定義、使用箇所、公式資料を区別して挙げる。外部ツールへの転送は「Strata がどの値をどう渡すか」を主に書く。
