## 役割

Metal 用の手動回帰プローブ `metal/tests/serve_probe.py` が、engine の標準エラーと起動情報を書き込むログファイルの出力先ディレクトリを指定します。通常の Strata アプリ、CLI、engine の設定ではありません。このスクリプトはコメントで「単体テストの一部ではない」とされ、Gyro-S または Flash-Next モデルを必要とするプローブです。

## 値と判定

スクリプト起動時に一度、Python の `os.environ.get("STRATA_OUT", default)` で読みます。値を数値や真偽値として parse せず、空白除去、環境変数値の `~` 展開、範囲検査もありません。

| 状態 | `S` とログパス |
|---|---|
| 未設定 | `~/strata-mac/g023/out` の `~` を `os.path.expanduser` で展開したディレクトリを使う。ログ名は `probe-{NAME}.log`。 |
| 空文字を設定 | fallback は使わず、`os.path.join("", "probe-{NAME}.log")` となる。相対パスで、プローブを起動した作業ディレクトリにログを作る。 |
| その他の値 | その文字列をディレクトリとして `os.path.join` に渡す。相対パスはプローブを起動した作業ディレクトリ基準。設定値に含む `~` は展開しない。 |

環境変数が未設定かどうかだけが fallback を決めます。設定値が存在していても、そのディレクトリの作成や妥当性確認はこのスクリプトでは行いません。

## 有効になる条件

- `metal/tests/serve_probe.py` を直接実行する場合に限ります。リポジトリ内の全ソースを検索した結果、同名の参照はこの1か所だけでした。
- `STRATA_REPO` は `STRATA_OUT` の読み取りより前に必須参照されるため、未設定ならスクリプトはそこで失敗します。`STRATA_CFG` も必須ですが、これは `STRATA_OUT` を読み取った後に参照されます。未設定ならログを使う処理へ進む前に失敗します。`STRATA_PROMPTS` は未設定時に別の既定ディレクトリへ fallback します。
- スクリプトのログパスは `StrataEngine` に渡され、サーバー側は指定されたログを追記モードで開きます。親プロセスの標準エラーも同じログへ渡します。指定したディレクトリが存在せずログを開けない場合、プローブの engine 起動処理は `OSError` で失敗します。

## 実行時の詳細

`STRATA_OUT` はスクリプトのトップレベルで一度取得されます。ログファイル名は `probe-{NAME}.log` で、`NAME` は第2コマンドライン引数（省略時 `agent`）です。変数値の変更は、プロセス起動後には反映されません。

この変数自身についてのログ出力や警告はありません。結果として指定先にプローブのログファイルが作られ、スクリプトは標準出力に `READY ...`、生成統計、`PROBE_DONE` を出します。`STRATA_OUT` はこれらの標準出力先を変更しません。
