# `STRATA_Q2_WARP`

調査対象: Strata `main` の HEAD `477ac13cbe8e582c20484871ce459d20d82df09d`（2026-10-17 時点）。対象は Strata 所有ソース。

## 役割

CUDA の native MMVQ における Q2_0 の専用 warp-row カーネルを選択します。対象カーネルは1 warp内で4出力行を処理し、1〜4列を扱います。通常の Q2_0 MMVQ カーネルを置き換える経路で、変数は計算結果ではなくカーネル選択を制御します。コードコメントは既存カーネルと bit-for-bit 同じ出力になる設計としています。

## 値と判定

変数が設定されている場合、値全体を数値変換せず、先頭文字だけを調べます。

| 値 | `STRATA_Q2_WARP` の判定 |
|---|---|
| unset | GPU と `STRATA_SM75_PERF` による既定判定へ進む |
| 空文字 | 有効（設定値の先頭文字は `\0` であり `'0'` ではない） |
| 先頭文字が `0`（例: `0`, `0abc`） | 無効 |
| その他すべて（例: `1`, `2`, `true`, `false`, 空白始まり） | 有効 |

大文字小文字、後続文字、数値としての妥当性は検査されません。明示値は `STRATA_SM75_PERF` による既定判定より優先され、`1` 以外でも先頭が `0` でなければ有効です。

未設定時は、CUDA のデバイス能力を取得でき、能力値が sm_75（または `STRATA_EMULATE_CC` により sm_75 として扱われる値）であり、かつ `STRATA_SM75_PERF` が `atoi` で非ゼロになる場合に有効です。`STRATA_SM75_PERF` は空文字や数値変換できない文字列なら0、`1tail` や負数など `atoi` が非ゼロを返す値なら有効です。その値は同ヘッダー内で初回評価時にキャッシュされます。

## 有効になる条件

- この選択分岐は CUDA コンパイル時（`__HIPCC__` 未定義）にだけ実行されます。HIP 経路では専用カーネルへの分岐がコンパイル対象外です。
- `native_q2_0_mmvq()` が呼ばれ、列数 `ncols` が4以下である必要があります。`ncols == 1` は複数列レイアウト設定に関係なく候補になります。2〜4列では `g_multi_exact` が真の場合だけ候補です（初期値は真で、ネイティブ MMVQ API から変更可能）。
- Q2_0 の形状検査も通る必要があります。共通検査は `1 <= ncols <= 8` と `n_in > 0` かつ64要素ブロックで割り切れることを要求します。列数5〜8ならこの環境変数が有効でも専用カーネルを使わず、従来経路へ進みます。
- CUDA デバイス問い合わせに失敗した場合、または未設定時に選択対象デバイスが既定条件を満たさない場合、専用カーネルは選ばれません。デバイスごとの既定結果は ordinal 0〜15 の範囲でキャッシュされ、範囲外の ordinal は無効扱いです。明示設定時はこのデバイス判定を通さずに真偽が決まります。

## 実行時の詳細

環境変数判定は `q2_0_warp_rows_on()` 内の function-local `static const int` で初回評価時に一度だけ保存されます。初回判定後にプロセス環境を変更しても反映されません。unset の場合に必要となる `STRATA_SM75_PERF` も `sm75_series()` の static 値として初回に読み取られます。

専用経路に入ると、列数に応じて `q2_0_warp_rows_kernel<1>` から `<4>` のいずれかを CUDA stream に enqueue し、launch error があれば `native MMVQ launch: ...` という例外を投げます。専用経路を選んだことを示す環境変数固有のログはこのコードにありません。`native_q2_0_f32()` は先に Q8_1 への量子化を enqueue してから同じ MMVQ 関数を呼ぶため、この選択条件を共有します。
