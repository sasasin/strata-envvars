# `STRATA_VARGS`

調査対象: Strata `main` の HEAD `477ac13cbe8e582c20484871ce459d20d82df09d`（2026-10-17 時点）。外部ライブラリの環境変数は対象外。

## 役割

Qwen 3.6 の画像 encoder 比較用スクリプト `tools/qwen35/q36_venc.py` が起動する `strata-vision` プロセスに、追加のコマンドライン引数を渡します。一般の Strata CLI やサーバーの設定としては読み取られず、この補助スクリプトを使う場合に限られます。比較スクリプト `q36_vision_cmp.py` は既定でこの encoder スクリプトを起動します。

## 値と判定

| `STRATA_VARGS` | `VARGS` | 追加引数 |
|---|---|---|
| 設定あり（空文字を含む） | 任意 | `STRATA_VARGS` の値を使う。空文字なら追加なしで、`VARGS` にフォールバックしない |
| 未設定 | 設定あり | `VARGS` の値を使う |
| 未設定 | 未設定 | 空文字を使い、追加なし |

選ばれた文字列を Python の `str.split()` で分割し、得られた各要素をそのまま `Popen` の引数リストに追加します。分割は空白区切りで、シェルは介さず、シェルの引用符やエスケープ規則では解釈されません。値に複数単語の一つの引数を表す引用符を書いても、その引用符を含む一引数にはなりません。

## 有効になる条件

この値を読むのは `tools/qwen35/q36_venc.py` のみです。`tools/qwen35/q36_vision_cmp.py` は `--venc` で別スクリプトを指定できますが、既定では同じディレクトリの `q36_venc.py` を選び、そのスクリプトを Python 子プロセスとして実行します。別の encoder スクリプトを指定した場合、そのスクリプトがこの環境変数を読むかどうかは別途実装次第です。

## 実行時の詳細

`q36_venc.py` は起動時に環境を参照してコマンドを組み立てます。実行形式は `[EXE, "--mmproj", MMPROJ, "--model", MODEL, ...追加引数]` です。環境変数はこの時点で一度読むため、同じスクリプト実行中に後から環境を書き換えても既に組み立てた引数には反映されません。

`subprocess.Popen` に `env` を渡していないため、`strata-vision` 子プロセスには通常の環境継承も行われます。ただし、このコードが `STRATA_VARGS` または `VARGS` 自体を子プロセス向けに設定・変更する処理はありません。スクリプトは子プロセスの標準入出力を使って `ENC` 要求を送り、画像ごとの応答や生成された `.sve` ファイルのヘッダー・統計を表示します。
