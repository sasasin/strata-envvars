# `STRATA_VISION_ENCODE_S`

調査対象: Strata `main` の HEAD `011c9e600a93bbc9fd451c563501b5831c32bbca`（2026-10-22 時点）。

## 役割

`strata --serve` の画像エンコーダーに `ENC` コマンドを送った後、応答1行を待つ時間（秒）を設定します。対象はサーバー内の読み取り待ちであり、画像のダウンロード、形式変換、エンコーダー起動時の `READY` 待ちは別処理です。

## 値と判定

| 環境変数の状態・値 | 使用される待ち時間 |
|---|---:|
| 未設定 | 300 秒 |
| Python の `float()` で変換できない文字列（空文字を含む） | 300 秒に戻る |
| 変換後が 0 以下（0、負数、`-0.0` など） | timeout なしで待つ |
| 変換後が正数 | その秒数 |

読み取りは `float(os.environ.get(name, default))` なので、前後の空白を含む Python 浮動小数点表記も変換対象です。整数への丸めや上限・下限 clamp はありません。`nan` / `inf` なども `float()` では変換できますが、有限値かどうかの検査はなく、そのまま待ち API に渡ります。これらの特殊値を使った際の待ち API の挙動は、この変数の実装だけからは保証できません。

## 有効になる条件

- `serve/server.py` がインポートされ、サーバープロセスで画像エンコード要求を処理する場合に使われます。
- 画像がエンコーダーのハッシュキャッシュにあれば、エンコード待ちは発生せず、この timeout も使いません。
- 有効な正数を設定しても、エンコーダーが応答しなければ期限でプロセスを終了します。0 以下にするとこの応答待ちの timeout は無効です。
- `STRATA_VISION_READY_S` はエンコーダー起動時の `READY` 行待ちを制御する別変数です。`STRATA_VISION_ENCODE_S` はそちらを変更しません。

## 実行時の詳細

値は `server.py` のモジュール初期化時に `VISION_ENCODE_S` へ一度読み込まれます。サーバー起動後の環境変数変更は再読込されません。各キャッシュミスで `ENC <画像ファイル> <埋め込みファイル>` を送信・flush した後、`_readline()` がこの秒数だけ応答行を待ちます。

期限切れになると `_readline()` はエンコーダープロセスを kill し、`RuntimeError`（`the image could not be read: it said nothing for N s`）を送出します。`Vision.encode()` は `stopped` を true にして同じ理由を `ValueError` として伝えます。処理中に書いた一時画像ファイルは `finally` で削除されます。通常のユーザー画像では画像要求のエラーになり、ツールが返した画像では `_note_unreadable_tool_images()` が理由をログに出して、その画像を `[image omitted: ...]` のテキストへ置き換えます。
