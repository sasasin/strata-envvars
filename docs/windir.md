# `windir`

調査対象: Strata `main` の HEAD `a0116b2782a5b82622358c04a06496485d12b2d6`（2026-10-13 時点）。外部ライブラリの動作は対象外。

## 役割

`windir` は `tools/strata_mcp.py` の MCP サーバーが、Windowsでインストール先の `data_dir` を検査するときに使うシステムフォルダー候補の一つです。指定先がこのフォルダーと同じか配下にある場合、新しいデータフォルダーとして拒否します。環境変数は Strata のエンジンでは読まれません。

## 値と判定

| 状態 | 処理 |
|---|---|
| 未設定 | `os.environ.get("windir")` が `None` になり、システムフォルダー一覧に追加されない。 |
| 空文字 | 空文字は偽値として一覧から除外される。 |
| 非空文字 | その文字列を `Path` に変換し、絶対パス化・実パス化・Windowsの大文字小文字正規化をして比較対象にする。 |

文字列の独自パース、値域検査、既定値の補完はありません。`system_folders()` は `SystemRoot`、`windir`、`ProgramFiles`、`ProgramFiles(x86)`、`ProgramData`、`ProgramW6432` を同列に扱います。優先順位はなく、各変数が非空ならそれぞれ比較対象になります。

`data_dir` 入力には `os.path.expandvars(raw)` も適用されます。そのためWindowsの環境変数形式 `%windir%` が入力中にあれば、パス検査前に展開されます。

## 有効になる条件

- MCPサーバーの実行環境がWindows（`os.name == "nt"`）の場合だけ、`system_folders()` は環境変数由来の一覧を返します。その他のOSでは固定された Unix システムパスの一覧を使い、`windir` は参照しません。
- `strata_install` の `data_dir` 引数が指定され、かつ指定先が既存のStrataデータフォルダー、Strataフォルダー内、または既定の `Strata-data` フォルダーではないとき、新規フォルダーの検査に進みます。
- 新規フォルダーは絶対パスで、親フォルダーが存在し、フォルダー名が `Strata` で始まる必要があります。条件を通過した後にシステムフォルダー一覧と比較されます。
- `windir` が未設定または空でも、他のシステムフォルダー環境変数による検査や、絶対パス・名前・親フォルダーなどの検査は引き続き行われます。

## 実行時の詳細

`WIN` はモジュール読み込み時に `os.name == "nt"` で決まり、`check_data_dir()` は指定されたインストール先を処理するたびに呼ばれます。`system_folders()` もその検査中に呼ばれ、`windir` を含む環境値を都度読みます。値をモジュール初期化時にキャッシュするコードはないため、同一プロセス内で環境値を変更した後の検査では新しい値が参照されます。

正規化した指定先 `n` がいずれかのシステムフォルダー `f` と等しいか、その配下なら、`ToolError("data_dir {raw!r} is inside a system folder")` を送出します。MCPツールの呼び出し側にはツールエラーとして返り、`strata_install` の後続処理へは進みません。`windir` の値を表示する専用ログや警告はありません。
