## 役割

`MMVQ_IL_ONLY` は通常の Strata 実行ファイルの設定ではなく、CUDA テスト用実行ファイル `mmvq_il_parity` が実行するテストケースを名前で絞るための変数です。Strata 本体のエンジン、モデル計算、生成結果を制御する読み取り箇所は見つかりませんでした。

## 値と判定

`mmvq_il_parity` の `main()` で `std::getenv("MMVQ_IL_ONLY")` を一度呼び、値が存在する場合は各ケース名に対して `std::strstr(c.name, only)` を使います。文字列全体の比較や数値変換はなく、大文字小文字を区別する部分文字列検索です。

| 値 | ケース実行の判定 |
|---|---|
| 未設定 | `CASES` の全ケースを実行 |
| 空文字 | 空文字列は全てのケース名に含まれるため、全ケースを実行 |
| ケース名に含まれる文字列 | その部分文字列を含むケースだけ実行 |
| どのケース名にも含まれない文字列 | `CASES` のケースは実行しない |

部分一致は大文字小文字を区別します。たとえばケース名の `Q6_K` を含む値なら該当ケースが残りますが、`q6_k` は一致しません。空白や記号も特別扱いされず、単なる検索文字列です。

## 有効になる条件

CMake で `STRATA_ENABLE_CUDA` が有効な場合に `mmvq_il_parity` ターゲットと CTest の `mmvq_il_parity` テストが登録されます。`MMVQ_IL_ONLY` はこのテスト実行プロセス内でのみ使われます。通常のStrataエンジンや他のテストへの適用は、対象ソースで確認できませんでした。

## 実行時の詳細

テストプログラムの起動後、`main()` が変数を一度読み、`CASES` の各名前を順に調べます。フィルターは `run_case()` の呼び出しだけを制御します。環境変数が設定されていても `check_tables()` は常に先に実行され、`--bench --emit-table` のテーブル出力処理もケースフィルターとは独立して続きます。

起動後の環境変更を再読込する処理はありません。子プロセスへの転送や上書きもこの実装にはありません。環境変数名が候補一覧に含まれているものの、調査したHEADではアプリケーション設定ではなく、CUDAテスト専用のケース選択フックです。
