## 役割

`--data-dir` で新しいモデルデータ保存先を指定したとき、同じ PC 上ですでに使っているモデルファイルを新しい保存先へ移す指定です。省略時は既定で既存ファイルを残しますが、対話実行では移動するか質問され、選択できます。保持を選んだ場合は新しいダウンロードだけが新しい保存先に入ります。

## 使い方

```bash
python3 setup.py --data-dir /Volumes/Models/Strata-data --move-data
```

Apple Silicon の macOS で `setup.py` を実行すると Metal 用の `engine/metal/setup_mac.py` に引数が渡されます。

## 値と既定値

値は不要です。Mac 用 parser は `action="store_true"` で登録しており、指定時は真、未指定時は偽です。フラグ自体に追加の値検証はありません。移動先の妥当性は、併用する `--data-dir` の値に対して検査されます。

## 実行時の動作

Mac 用 setup は `--move-data` を受理し、共通の `data_folder_for()` に引数を渡します。そこで `--move-data` は移動可否の `move` 引数に、`--yes` は対話確認を避ける `yes` 引数に渡されます。異なる `--data-dir` があり、既存モデルが移動可能な場所にあるとき、このフラグがあれば確認を挟まず移動経路に進みます。フラグがなく `--yes` もない場合は対話で選択し、`--yes` だけが指定された場合は既存モデルを残す側になります。

移動対象の探索元はこの Strata フォルダ、登録済みの他の Strata インストール、記憶済みのデータフォルダなどです。探索元と移動先が同じ場所なら対象外で、同じファイルシステム上にない探索元は移動せず、その場所で引き続き使われます。移動処理は `models` を移動先に統合し、`packs` 内の各項目と `mtp` は移動先に同名項目がない場合に移動します。移動後は関連するモデル設定内のパスを付け替えます。移動元にファイルが残る（使用中、または移動先に既存コピーがある）場合は警告し、残っていなければ完了を表示します。

移動先に既存モデルが見つからない場合は、データフォルダ設定をその移動先にする処理へ進みます。正常経路では `settings.json` の `data_dir` と登録済みインストール一覧を保存します。`--data-dir` がなくこのフラグだけを指定した場合は、共通処理内の「新しい移動先を指定した場合」の分岐に入らず、このフラグによる移動指定は作用しません。

## 適用条件と副作用

この文書のコマンド階層は Apple Silicon Mac 用です。共通の保存先処理は、移動先が既存の保存先と異なり、既存モデルがある場合に `--move-data` の選択を使います。移動元と移動先が異なるファイルシステムの場合、コードは移動を行わず移動元を引き続き利用する場所として返します。

移動先が相対パス、ファイル、書き込み不能な場所、システムフォルダなど `folders.problem()` の検査で不適切と判定され、かつ `--data-dir` が明示されていれば、setup はエラーを表示して終了コード 1 で停止します。その経路では「何もダウンロードまたは変更していない」と伝え、移動も保存先設定も行いません。一方、移動中の個々のファイルが使用中などで動かせない場合は残存ファイルの警告経路になります。保存設定の書き込み自体が失敗した場合は共通処理が警告を出します。

## 出力とエラー

移動元ごとに移動完了、または一部が残った旨を出力します。無効な明示移動先は共通の `fail()` 経路でエラーと再実行案内を出して終了コード 1 になります。移動先フォルダを作れない場合は警告を出して現在の Strata フォルダを保存先として使う fallback があります。
