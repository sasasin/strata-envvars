## 役割

`--data-dir` で現在と異なるデータフォルダーを指定した場合に、見つかった既存モデルデータを新しい場所へ移す選択を明示します。Mac 側 parser の help も「`--data-dir` とともに使い、ここにあるモデルファイルを新しいフォルダーへ移動する」と説明しています（`metal/setup_mac.py:339-341`）。

## 使い方

Strata ソース checkout のルートで、既存モデルを新しいフォルダーへ移し、モデル起動を行わず setup する例です。

```sh
./setup.sh --setup --data-dir "$HOME/Strata-data-new" --move-data --no-start
```

`setup.sh` は引数を `setup.py` に渡し、macOS の通常実行では `setup.py` が `metal/setup_mac.py` に同じ引数を渡します（`setup.sh:6,76`; `setup.py:7703-7707,9068-9069`）。

## 値と既定値

- Mac parser は `action="store_true"` で登録し、値を受け取りません。省略時は偽で、重複指定しても真です。`--data-dir` との組み合わせを必須とする parser validation はありません（`metal/setup_mac.py:339-344`）。
- 移動先は `--data-dir DIR` で指定します。この値は共通処理で `expanduser()` と `resolve()` を行い、利用可能なディレクトリーか検証されます（`setup.py:6387-6393`）。
- 既存データがあり、移動フラグを付けず `--data-dir` を変えた場合、Mac parser の `--yes` は既定で偽なので、対話可能なら保持 (`keep`) / 移動 (`move`) を尋ねます。質問の既定回答は `keep` です。`--yes` を付けると質問を省略して保持側になります（`metal/setup_mac.py:344`; `setup.py:6410-6426,930-944`）。

## 実行時の動作

Mac 用 `main()` は処理の冒頭で `data_folder_for(a)` を呼びます。既存設定だけでモデルを起動する経路もこの呼び出しの後です（`metal/setup_mac.py:364-371`）。引数は `setup.py` の共通 `data_folder()` に渡されます（`setup.py:6472-6475`）。

`--data-dir` が記憶済みフォルダーと異なり、既存データが見つかった場合、`--move-data` は確認を飛ばして移動処理を選びます。フラグなしで保持を選んだ場合は既存データを元に残し、新しいダウンロード先だけを変更します。`--set-default-data-dir` も併用した場合、この保持分岐でも指定先が `settings.json` の `data_dir` に保存されます（`setup.py:6410-6434`）。

移動対象は Strata checkout、記録済みの他インストール、記憶済みデータフォルダーなどの候補から探されます。同じドライブにある `models/` はファイル単位で統合し、移動先に同名ファイルがあれば移動先を保持します。`packs/` の項目と `mtp/` は移動先に同じ項目がない場合に移します。モデル設定ファイル内のパスは、対象ファイルが移動先にあり元の場所にはない場合に更新されます。移動後に残ったデータがあれば警告し、元の場所も利用対象として返します（`setup.py:6404-6409,6441-6465,6308-6326,6329-6350`）。処理が移動分岐まで完了すると、指定先の `data_dir` と Strata install 一覧を設定へ保存します（`setup.py:6466-6469`）。

## 適用条件と副作用

- 明示的な移動選択が作用するのは、異なる `--data-dir` と、同じドライブ上にある既存データがある場合です。同じフォルダーを指定したときは、この選択分岐に入りません（`setup.py:6410-6417`）。
- `--data-dir` を指定せず `--move-data` だけを付けた場合、このフラグは明示的な移動選択を起こしません。ただし Mac setup は単純起動前にも共通 data-folder 処理を呼び、移動先を指定しない場合は記憶済みフォルダーへ同一ドライブ上のデータを集めます。この通常整理は `--move-data` の効果ではありません（`metal/setup_mac.py:365-371`; `setup.py:6381-6386,6435-6469`）。
- 別ドライブのデータは大容量移動の対象にならず、元の場所に残ります（`setup.py:6417,6441-6445`）。
- 明示した保存先が無効なら `fail()` が案内を表示して終了コード `1` で停止します。保存先の作成時に `OSError` が起きると警告し、Strata checkout を保存先にして続行します（`setup.py:6391-6402,904-909`）。
- ファイル移動は同一ドライブで rename を試し、移動できないファイルは元に残します。移動先に既存ファイルがある場合もそれを上書きしません（`setup.py:6301-6326`）。設定保存に失敗した場合は警告されます（`setup.py:6258-6265`）。

## 出力とエラー

- 確認時は見つかったモデルの場所と容量を表示し、`keep` / `move` を尋ねます。保持を選ぶと既存モデルを元に残し、新規ダウンロードを指定先に置く旨を表示します（`setup.py:6418-6432`）。
- 移動完了時は `[ok]` メッセージを表示します。移動できないファイル、または移動先にも同じデータがあるため元に残った項目があれば警告します（`setup.py:6461-6465`）。
- 質問が必要な経路で stdin が EOF になると `fail()` で案内を表示し、終了コード `1` になります（`setup.py:930-944,904-909`）。
