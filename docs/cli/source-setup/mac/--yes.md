| コマンド | Mac 用 `metal/setup_mac.py`（`setup.py` が Apple Silicon/macOS で委譲） |
| オプション | `--yes` |
| 別名 | なし |
| 値 | 値なしの真偽フラグ。省略時は `False`、指定時は `True`。 |

## 役割

Mac 用セットアップで対話質問に回答するとき、質問を表示せず各質問の推奨回答を選びます。現行 Mac 実装でこのフラグを `S.ask` に渡すのはモデルサイズ選択と画像対応の質問です。モデルサイズはメモリ量から推奨された項目、画像対応は `y`（有効）が選ばれます（`metal/setup_mac.py:433-451`）。

## 使い方

```sh
# Mac でモデルのセットアップを行い、選択質問には推奨回答を採用する
./setup.sh --setup --yes

# モデルを明示し、画像対応など残る質問には推奨回答を採用する
./setup.sh --setup --model <MAC_MODELS にあるモデル名> --yes
```

`setup.py` は macOS かつ Control モードでない場合、受け取った引数をそのまま `metal/setup_mac.py` に渡します（`setup.py:9330-9331`, `8309-8313`）。

## 値と既定値

値は取りません。`argparse` の `store_true` なので、未指定は `False`、指定は `True` です（`metal/setup_mac.py:390`）。同じフラグを複数回指定しても真偽値のままです。

このフラグが選ぶ「推奨回答」は質問ごとに異なります。モデル選択では実機メモリから求めた推奨モデルの番号、画像対応では `y` です。画像対応の回答は後続処理で画像エンコーダーの取得・ビルドと設定への有効化に使われます（`metal/setup_mac.py:435-451`, `515-522`, `597-600`）。

## 実行時の動作

Mac 実装の `S.ask(question, choices, default, yes)` は `yes` が真なら入力を求めず `default` を返します。偽の場合は質問を表示し、空入力なら既定値、有効な選択肢ならその回答を返し、無効な入力には選択肢を再表示します（`setup.py:849-863`）。

`metal/setup_mac.py` では、モデルを `--model` で指定していない場合にモデル番号を質問します。この質問で `--yes` を付けるとメモリに応じた推奨モデルが選ばれます（`metal/setup_mac.py:435-447`）。`--vision` が未指定なら画像対応を質問し、`--yes` では既定の `y` が採用されます（同 `450-456`）。`--model` や `--vision` を明示した場合、それぞれの質問は行われません。

`--yes` だけではセットアップモードに切り替わりません。Metal 設定が既にあり、`--setup`、`--model`、`--check`、`--no-start`、`--update`、`--build` のいずれもない場合は、質問処理より先に既存設定で起動します（`metal/setup_mac.py:415-417`）。また、モデル選択の対話予定を判定する feed 読み込みでは `--yes` が対話扱いを抑えます。ただし未知の `--model` または `--family` が指定されていれば feed 読み込み条件は別に成立します（同 `360-368`, `373`）。

## 適用条件と副作用

対象は `setup.py` から委譲される Apple Silicon/macOS の Metal セットアップ経路です（`setup.py:8309-8313`, `9330-9331`）。`--yes` は推奨回答を採用するだけで、Mac の互換性確認やモデルの取得・準備、Metal エンジンのビルド、設定ファイルと起動スクリプトの作成を省略しません。セットアップ経路はモデルファイル等を取得し、最終的に設定・スクリプトを書き、`--no-start` がなければサーバーを起動します（`metal/setup_mac.py:419-431`, `465-522`, `524-620`）。

非対話入力が尽きて `S.ask` に達した場合は、`--yes` がなければエラーとして終了し、`--yes` があれば各質問の既定値を返します（`setup.py:849-858`）。ただし明示的な `--model` や `--vision` は質問既定値を使う経路自体を置き換えます。

## 出力とエラー

`--yes` 自体に専用のメッセージ出力やファイル副作用はありません。推奨値を採用した後の出力と副作用は通常のセットアップ処理に従います。`S.ask` の質問中に標準入力が EOF になり、`--yes` がない場合は案内を表示して終了コード `1` で停止します（`setup.py:855-858`, `823-828`）。`--yes` の parser 登録には値の型や choices がなく、このフラグ自体に値検証はありません（`metal/setup_mac.py:390`）。
