## 役割

この parser は `--layer-split` を受理し、直後の引数を読み飛ばします。値を保存・検証せず、分割境界の指定や分割有効化には使いません。parser のコメントは「server のオプション」とし、この engine は自身の分割を行うと説明しています（`src/dsv41/ds4_main.cpp:1265`）。

## 使い方

```sh
strata-dsv41 --pack /path/to/model/maya-ds4 --serve --layer-split auto
```

この例の `auto` は parser に消費されるだけです。実際の GPU 選択・層配置は `--gpus`、`--tp` や利用可能メモリなどに基づく engine 側の処理で決まります。

## 値と既定値

- 値は必須です。末尾に値を付けずに指定すると、標準エラーに `--layer-split needs a value` と出して終了コード 2 で終了します（`src/dsv41/ds4_main.cpp:1202-1207,1265`）。
- 値は文字列として1引数分だけ消費されます。空文字列や任意の文字列もこの箇所では拒否されず、値の変換・範囲確認もありません（同 `1202-1207,1265`）。
- 繰り返し指定しても値は毎回破棄されるため、後勝ちの設定はありません。
- 既定値はありません。指定しなければこのオプションに関する処理はありません。
- 値の位置に別のオプション文字列を置いた場合も、その文字列が値として消費されます。

## 実行時の動作

引数 parser は `main` の冒頭で全引数を走査し、`--layer-split` に遭遇すると次の argv を読み進めて破棄します。`--serve` の有無や実行モードによる条件分岐はこの受理箇所にはありません（`src/dsv41/ds4_main.cpp:1200-1208,1263-1268`）。従って、このオプションは `--serve` を有効にしたり、モデル処理の開始後に設定を変更したりしません。

モデルの GPU は `--gpus` が空なら可視 GPU 全て、指定があればその ID 群です（`src/dsv41/ds4_model.cu:1870-1884`）。engine は `--tp` 等から GPU 群を作り、各 GPU 群の空きメモリを見積もって連続する層範囲を割り当てます（同 `1912-1945,2057-2101`）。この配置に `--layer-split` の値は参照されません。`--gpus` と `--tp` の指定方法・制約はそれぞれのオプション文書を参照してください。

## 適用条件と副作用

parser 上の受理に `--serve` などの適用条件はなく、値を消費する以外の副作用はありません。ただし、後続の引数解析やモデル起動は通常どおり続きます。GPU 構成に応じた層分割そのものは `Model::load` が行い、`--layer-split` の有無・値には連動しません（`src/dsv41/ds4_model.cu:1853-1856,1870-1884,2057-2101`）。

## 出力とエラー

- 値が欠けている場合、標準エラーに `--layer-split needs a value` を出して終了コード 2 になります（`src/dsv41/ds4_main.cpp:1202-1207,1265`）。
- オプション名自体は認識されますが、engine の `usage()` にある通常のオプション一覧には掲載されていません（同 `85-94,1265`）。
- 値の不正を理由とする警告・エラーは、このオプションの parser / 使用箇所では確認できません。通常のモデル読み込み・実行に起因する出力や失敗は別途発生し得ます。
