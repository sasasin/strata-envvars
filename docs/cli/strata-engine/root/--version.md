## 役割

エンジンのビルド時バージョンを1行表示して、処理を終了します。モデルの読込や推論を始めずに、実行ファイルのバージョンを確認できます。

## 使い方

```sh
strata --version
strata -V
strata generate --version
```

`main()` は `argv[1]` と `argv[2]` を検査するため、トップレベルでの指定に加えて `generate` の後に置いた指定も認識します。

## 値と既定値

このフラグは値を取りません。省略時にバージョン行は出力されず、通常の引数処理へ進みます。数値などの明示値を受け取る構文はありません。CMake の `PROJECT_VERSION` が `STRATA_VERSION` としてコンパイル定義され、現行ソースでは `0.1.49.2` です。実行ファイルは `strata <STRATA_VERSION>` と出力するため、このソース revision の標準的なビルドでは `strata 0.1.49.2` となります。

## 実行時の動作

通常の引数 parser に入る前に、`argv[1]`、次に `argv[2]` の文字列を `--version` または `-V` と完全一致で比較します。一致すると標準出力へ `strata <バージョン>\n` を出して終了コード `0` で戻ります。したがって、たとえば `strata generate --version` でも認識されます。検査対象より後ろの引数はこの早期判定では調べられません。

早期判定の前に `stdout` のバッファリングを無効化します。また HIP を有効にした Windows ビルドでは、実行ファイルの隣に `rocm\\bin` が存在すれば DLL 検索ディレクトリに設定します。フラグ一致後は通常の parser や GPU 初期化へ進みません。引数の残りは検証されず、`--version` より前または後に追加の引数があっても、この早期分岐で終了します。

## 適用条件と副作用

この処理は `src/program/generate.cpp` の `main()` に実装され、引数の1番目または2番目にフラグがある場合に適用されます。GPU に触れる前に終了することは同箇所のコメントと分岐順序で確認できます。通常経路で行うモデル読込・推論は実行しません。バージョン確認のためのファイル書込やネットワーク処理はこの分岐にはありません。

引数の3番目以降だけに `--version` / `-V` を置いた場合は、この早期判定に一致せず通常の引数処理へ進みます。その場合の扱いは後続 parser によります。

## 出力とエラー

- 一致時: 標準出力に `strata <バージョン>` と改行を出力し、終了コード `0` を返します。
- この分岐自体に値の validation やエラー出力はありません。後続引数の妥当性も判定しません。
