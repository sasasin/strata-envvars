# `--stop-eos`

調査対象: Strata commit `d46f5f268f8ed797e83a5c63a69bffbd7a581cf6`（`2026-11-25` 時点）。

| 項目 | 内容 |
| --- | --- |
| ツール ID | `strata-engine` |
| コマンド | `strata generate`（推論エンジン） |
| オプション | `--stop-eos` |
| 別名 | なし |
| 値 | 取らないフラグ |

## 役割

生成したトークンが終端 ID に一致したとき、通常のトークン生成を終了します。既定の終端 ID は `248044`（`<|endoftext|>`）と `248046`（`<|im_end|>`）です。ID の集合は `--eos-ids` で置き換えられます。

## 使い方

```sh
strata generate --pack /path/to/pack --tokens "248045,1234" --stop-eos
```

`--tokens` にはプロンプトのトークン ID を指定します。実際に使う pack と ID に置き換えてください。

## 値と既定値

- `--stop-eos` は値を取りません。parser は指定時に内部フラグを `true` にします。省略時は `false` です。
- 既定の終端 ID リストは `248044, 248046` です。`--eos-ids LIST` を指定するとリストが置き換わり、終端停止も有効になります。
- `--eos-ids` のリストはカンマまたは空白区切りの整数で、空ではないこと、各 ID が `[0, 2147483647]` の整数であることが必要です。複数回指定時は後の指定がリストを置き換えます。
- `--stop-eos` の重複指定は同じ真偽値を再設定します。フラグの後ろに値を置く構文はありません。

## 実行時の動作

通常の生成ループでは、プロンプト最終位置以降に生成されたトークンを出力列へ追加し、その後 `--stop-eos` が有効で、生成 ID が `--eos-ids`（未指定なら既定リスト）に含まれるかを判定します。一致すればループを抜けます。このため終端 ID は停止判定前に生成列へ追加され、最終 `output` に含まれます。プロンプト中の終端 ID だけではこの判定は発生しません。

`--max-new` の上限確認は終端 ID 確認より先です。上限に達した位置で終了する場合は、後続の EOS 判定を行いません。投機的デコードでも終端 ID を出力列へ追加し、そのラウンドの出力を終えます。また、終端 ID で終わった状態は投機ループの起動条件へ渡され、追加の投機生成を抑止します。

`--serve` でトークン入力がない起動経路では、エンジンがリクエスト用の初期トークンを設定する際に `stop_eos` も有効にします。この経路では `--stop-eos` を省略しても内部的に有効です。

## 適用条件と副作用

- EOS 判定は生成位置に対してのみ行われます。指定 ID が生成されなければ、このオプションによる早期終了は起きません。
- GPU/backend、モデル形式による別の値補正は parser と参照箇所では確認できませんでした。これらの組み合わせ全てでの動作までは調査していません。
- このオプション自体によるファイル変更や追加プロセス起動はありません。生成処理の終了位置と出力トークン数に影響します。

## 出力とエラー

正常終了後、生成列は標準出力の `output` 行に ID 列として表示されます。EOS に一致した ID もその列に含まれます。`--stop-eos` 自体に値の validation はありません。`--eos-ids` が空、整数でない、または `[0, 2147483647]` 外の値を含む場合は stderr にエラーを出して終了コード `2` で拒否されます。オプション名の誤記など未認識引数も stderr に `unknown argument` と usage を出し、終了コード `2` です。
