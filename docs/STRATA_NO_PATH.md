# `STRATA_NO_PATH`

調査対象: Strata `main` の HEAD `011c9e600a93bbc9fd451c563501b5831c32bbca`（2026-10-22 時点）。外部ライブラリの環境変数は対象外。

## 役割

Windows 用 PowerShell インストーラー `packaging/install.ps1` が、インストール先の `bin` をユーザー PATH に追加するかを制御します。値が文字列 `1` と等しい場合、ユーザー PATH とインストーラー実行中のプロセス PATH の更新を省略し、実行ファイルの場所を表示します。インストール自体やターミナルの配置は引き続き行われます。

## 値と判定

| 値 | PATH 更新 | 完了時の表示 |
|---|---|---|
| 未設定、空文字、または `1` 以外 | 行う | `  (open a new terminal window if the command is not found yet)` |
| `1` | 行わない | `  (the program is <current>\bin\strata.cmd)` |

PowerShell の `-eq` / `-ne` による文字列比較で、整数への変換や先頭文字判定はありません。したがって `01`、`true`、` 1` は `1` と等しくなく、通常どおり PATH を更新します。比較は既定で大文字小文字を区別しませんが、比較対象の文字列 `1` に関して大文字小文字の差はありません。

## 有効になる条件

- この変数を参照するのは Windows 用の PowerShell インストーラーだけです。スクリプトは Windows 以外ではエラー終了します。Linux/macOS 用の別インストーラー `install.sh` ではこの名前の参照はありません。
- インストール成功後、`$bin`（`%LOCALAPPDATA%\Strata\terminal\current\bin`、または `STRATA_DATA_DIR` を指定した場合の同等パス）をユーザー PATH に追加する処理に適用されます。
- PATH に同じ `$bin` が既にある場合、ユーザー環境変数の再設定は省略されます。それでも `STRATA_NO_PATH` が `1` 以外なら、インストーラーのプロセス内 `$env:Path` には `$bin` を追記します。

## 実行時の詳細

インストール先の展開、署名確認、`current` の設定が成功した後に変数を参照します。値が `1` 以外の場合、スクリプトはユーザー環境の `Path` を読み、セミコロンで分割した要素に `$bin` が完全一致で存在しなければ、末尾に追加してユーザー環境変数として保存します。その後、現在のインストーラープロセスの `$env:Path` にも `$bin` を追加します。既存の同一パスを比較するときは大文字小文字を区別しない PowerShell の `-notcontains` を使います。

値が `1` の場合はこの更新ブロックを丸ごと飛ばし、完了メッセージの後に実行ファイル `strata.cmd` の場所を表示します。`STRATA_NO_PATH` はインストーラー内で再読み込み・キャッシュされず、子プロセスにも引き渡す処理はありません。なお、変数の判定はインストール成功後に行われるため、PATH 更新を抑止してもインストール処理の前半には影響しません。
