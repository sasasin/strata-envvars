## 値と判定

| 環境値 | 処理 |
|---|---|
| 未設定 | 文字列 `"0.28"` を既定値にして `float()` で変換 |
| 有効な数値文字列 | Python の `float()` で浮動小数点数に変換し、プロンプト生成へ渡す |
| 空文字・変換できない文字列 | `float()` が `ValueError` を送出する。スクリプト内で捕捉されないため、ベンチマーク処理はそこで異常終了する |
| `0` 相当 | 変換自体はできるが、プロンプト生成時の `tokens / ratio` で `ZeroDivisionError` になる |
| 負数 | 変換される。通常の正の token 数では `tokens / ratio` が負になり、本文追加ループは実行されず、空の合成本文になる |

文字列の真偽値判定や `1` との比較は行いません。正の有限値を渡した場合、生成側は本文の累積文字数が `tokens / ratio` 以上になるまで、ランダムな識別子付きの定型段落を追加します。そのため段落単位で目標文字数を超える場合があり、token 数との一致を保証する値ではありません。スクリプトのコメントも、実際の token 数は API 応答の `prompt_n` で確認するとしています。
