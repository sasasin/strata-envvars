# `ProgramW6432`

調査対象: Strata `main` の HEAD `7695859aa13afb248bdb4d36f9b2e95707db079d`（2026-10-12 時点）。対象は Strata 同梱の MCP サーバーを含む Strata 所有コード。

## 役割

Windows で MCP サーバーの `strata_install` が受け付ける新しい `data_dir` の置き場所を判定するため、システムフォルダー候補の一つとして読み取ります。`ProgramW6432` の値そのものをインストール先に設定することはなく、このフォルダー内（またはその配下）を新しいデータ保存先にすることを拒否するために使います。

## 値と判定

`os.environ.get("ProgramW6432")` で文字列を取得します。値を数値や真偽値に変換せず、文字列比較もしません。

| 状態 | 処理 |
|---|---|
| 環境変数が未設定 | `None` になり、システムフォルダー一覧から除外 |
| 空文字 | 偽として一覧から除外 |
| 空でない文字列 | `norm()` でパスに正規化し、Windows のシステムフォルダー一覧に加える |

`norm()` は絶対パス化、実パス解決（リンク解決を含む）、Windows での大文字小文字を区別しない形式への正規化を行います。存在確認や値の妥当性検査はこの関数では行いません。相対パスなどが設定された場合の正規化結果を含め、誤った値への個別 fallback はありません。

## 有効になる条件

この読み取りは `os.name == "nt"` のときだけ実行されます。Windows 以外では `system_folders()` は Unix 系の固定パス一覧を返し、この環境変数を参照しません。

`ProgramW6432` による拒否判定は、新規のデータフォルダーを指定する経路に限られます。入力されたフォルダーが現在のデータフォルダー、Strata 本体内、または既定の `Strata-data` フォルダーなら先に許可されるため、システムフォルダー判定には進みません。

## 実行時の詳細

`check_data_dir()` は新しい保存先候補について `system_folders()` を呼び、正規化した候補パスが一覧のいずれかと一致するか、その配下にあるかを調べます。一致した場合は `ToolError("data_dir ... is inside a system folder")` を送出します。`system_folders()` は呼び出しごとに環境を読み取るため、モジュール読み込み時に値をキャッシュする実装ではありません。

`ProgramW6432` は `SystemRoot`、`windir`、`ProgramFiles`、`ProgramFiles(x86)`、`ProgramData` と並列に扱われます。これらの値の優先順位はありません。複数の値が設定されていればそれぞれを拒否対象に追加し、未設定または空の値だけを飛ばします。拒否時のエラーは MCP のツールエラーとして呼び出し元に返ります。
