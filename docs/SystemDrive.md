# `SystemDrive`

調査対象: Strata `main` の HEAD `a0116b2782a5b82622358c04a06496485d12b2d6`（2026-10-13 時点）。対象は Strata 所有ソース。環境変数の参照は `setup.py` と `serve/server.py` にあります。

## 役割

Windows のセットアップ診断で、自動管理ページファイルの現在のドライブが検出できない場合に調べるドライブを選びます。また、画像エンコーダー用の作業ディレクトリを一時ディレクトリやカレントディレクトリに作れない（またはパスに空白がある）場合の候補として、システムドライブ直下を指定します。

## 値と判定

| 読み取り箇所 | 未設定 | 設定時の処理 |
|---|---|---|
| `setup.py` のページファイル診断 | `C:` を使う | 空文字も `C:` にフォールバック。それ以外は値の先頭1文字を大文字化してドライブ文字として使う。形式や長さは検証しない |
| `serve/server.py` の画像エンコーダー作業ディレクトリ | `C:` を使う | 値全体に `os.sep` を連結し、`Path` に渡す。空文字は既定値に置換されず、値の妥当性やドライブ文字の大文字小文字も検証しない |

どちらも値を数値や真偽値として parse しません。`setup.py` では先頭文字だけが使われ、たとえば `d:\\data` なら `D:` 相当です。`serve/server.py` では値全体がパス候補になります。設定値を変更した場合、setup の診断関数または `Vision.work_dir()` が次に呼ばれた時点で読み直されます。モジュール読み込み時のキャッシュはありません。

## 有効になる条件

- **セットアップ診断:** `WIN` が真（`os.name == "nt"`）で、Windows の `PagingFiles` レジストリ値を読み取れた場合に限り `page_file_setting()` が処理を続けます。`ExistingPageFiles` にドライブが一つでも含まれれば、その検出結果が優先され、`SystemDrive` は使われません。検出結果が空の場合にだけ `SystemDrive`（または `C:`）が使われ、さらに `PagingFiles` のエントリーが `?:` のときの候補ドライブになります。明示ドライブのエントリーには影響しません。
- **ページファイル警告:** ページファイルの推定値が 4 GB 未満の場合、setup は診断を警告として表示します。`SystemDrive` はこの推定値全体を直接設定するものではなく、上記の自動管理ドライブ推定に使われます。
- **画像エンコーダー:** `Vision` が構築されると `work_dir()` が呼ばれます。候補順は既定の一時ディレクトリ、カレントディレクトリ、`SystemDrive` 直下です。作成に失敗した候補や、空白を含む候補は次へ進みます。すべて失敗した場合は、既定の一時ディレクトリにもう一度作成を試みます。この経路に Windows 判定はありません。

## 実行時の詳細

setup の `page_file_setting()` は、Windows の Memory Management レジストリから `PagingFiles` と `ExistingPageFiles` を読みます。後者から現在のページファイルのドライブ文字が得られないとき、`(os.environ.get("SystemDrive") or "C:")[0].upper()` を既定ドライブにします。`page_file_gb()` は Windows のコミット量と、ドライブごとのページファイル設定・現在サイズ・空き容量からサイズを推定します。setup の PC 診断は推定値が 4 GB 未満なら `page_file_advice()` の警告を出します。`SystemDrive` の異常な値はドライブ文字として検査されず、その文字で `drive:\` を組み立てるため、意図しないドライブの照会や照会失敗につながりえます。照会できないドライブは `_drive_mb()` が `None` を返し、呼び出し元はサイズを 0 として扱います。

サーバー側では `Vision.__init__()` が `work_dir()` の戻り値を `self.dir` に保存し、画像エンコーダーを `cwd=self.dir` で起動します。候補ディレクトリが作れても、そのパスに空白があれば空ディレクトリの削除を試みて次の候補へ進みます。最後の既定一時ディレクトリ候補は空白検査なしです。`Vision` の作成後に環境変数を変更しても、既存インスタンスの `self.dir` は変わりません。
