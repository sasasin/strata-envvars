# `DS4_ENGRAM_CACHE_MB`

調査対象: Strata `main` の HEAD `4b9e05a2a806a3fe24f7b2560d98626c37dade35`（2026-10-26 時点）。外部ライブラリの環境変数は対象外。

## 役割

DSV41 実行経路の Engram（n-gram memory）行キャッシュ容量を MiB 単位で指定します。キャッシュに保持された行は、同じ行が再度必要になったときにモデルファイルから読み直さず、キャッシュからコピーされます。この設定はキャッシュの行数上限を変えます。キャッシュ全体を起動時に確保する指定ではありません。

## 値と判定

| 値 | 実装上の扱い |
|---|---|
| 未設定 | 使用可能 RAM から既定 MiB 数を計算する。RAM 使用可能量が取得不能なら 64 MiB。 |
| `0` または空文字 | `strtoull` の結果が 0 となり、キャッシュ容量 0 行。`put()` は保存しないため、再利用可能な行は保持されない。 |
| 正の整数文字列 | 十進 `strtoull` の結果を MiB として使用する。行数上限は `floor((MiB × 2^20) / row_bytes)`。 |
| その他の文字列 | `strtoull(e, nullptr, 10)` の結果をそのまま使う。先頭空白と符号の後に数字があればその数字列を変換し、後続文字列は検査しない（例: `12junk` は 12）。数字を変換できなければ 0。 |
| 負数・範囲外 | 値の検証や clamp はない。`strtoull` の符号・範囲処理結果を受け取り、その後 `mb << 20` を行う。errno や変換終端位置は調べないため、負数・オーバーフロー入力の結果を通常の容量値としては保証できない。 |

`row_bytes` は `pk.eg_hd + pk.eg_hd / 32` バイトです。これはキャッシュする Engram 1行のコードとスケールの領域に対応します。MiB から求めた容量は行数へ切り捨てられます。たとえば指定量が1行分に満たなければ容量は0行です。

未設定時は `ram_avail()` を MiB に切り捨てて64で割り、16 MiB 以上・256 MiB 以下に制限します。従って、取得できた使用可能 RAM が少なくても16 MiB、多くても256 MiBです。`ram_avail()` が未知値を返す場合は64 MiBです。

## 有効になる条件

- DSV41 モデルのロード処理で `pk.eg_layers > 0` の場合にだけ環境変数を読み、Engram reader と行キャッシュを初期化します。Engram 層がないモデルではこの変数は参照されません。
- 値の読み取りはモデル初期化時です。リクエストごとには読み直さないため、初期化後の環境変更はこのキャッシュ容量に反映されません。
- 同じ初期化ブロックで `DS4_ENGRAM_THREADS` が reader のスレッド数を決めますが、キャッシュ容量とは別の設定です。
- ソース内の参照は `src/dsv41/ds4_model.cu` のみです。`docs/DETAILS.md` と `docs/DEEPSEEK41.md` に、この変数の追加条件や推奨値、性能測定値は見当たりません。

## 実行時の詳細

モデル初期化時に Engram 行サイズを求め、上記の MiB 数から最大行数を算出して `EgRowCache::init()` に渡します。キャッシュは key から行を引く構造で、key は Engram の行 ID と層番号から作られます。`eg_issue()` は各 window の Engram 行を要求するときにキャッシュを検索し、ヒットすればコードとスケールを宛先へコピーします。同じ batch 内で重複した行も1回だけ読み、残りへコピーします。読み取りに成功した行は `eg_finish()` でキャッシュへ格納されます。キャッシュが満杯なら clock eviction で既存行を置き換えます。

容量0では cache `put()` が常に null を返し、行を保持しません。容量が正の場合も保存用メモリは必要に応じて増え、行データは4096行単位のブロックで確保されます。そのため指定 MiB 数は行数上限を計算する基準であり、確保バイト数の厳密な上限ではありません。

`--verbose` の場合、初期化時に stderr へ `Engram rows read on ...; row cache ... MB (... rows)` の行を出し、設定された MiB 数と算出した行数を表示します。実行統計では、キャッシュが保持する行数・容量と要求行に対する cache hit/read 数が DSV41 の status に反映されます。コード上でこの設定だけに紐づく警告や性能保証はありません。
