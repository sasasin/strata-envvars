# `STRATA_DS4_SLOT_DIR`

調査対象: Strata `main` の HEAD `7dd5cf18e68c639a8773e096c5c79f971ea2a9f5`（2026-10-25 時点）。

## 役割

DeepSeek-V4.1 用の同梱エンジン `strata-dsv41` が、会話状態のディスクスロットを置くディレクトリを指定します。ここに会話状態の `.bin` と、そのモデル識別情報・トークン列・サイズを記録する `.meta` を保存し、後のリクエストやエンジン再起動後に読み戻します。Strata の通常エンジンではこの名前を読みません。

## 値と判定

| 状況 | 使用するディレクトリ |
|---|---|
| `STRATA_DS4_SLOT_DIR` が未設定で、スロット保存が有効 | エンジンに渡された pack ディレクトリの `slots/` |
| 設定あり（空文字を含む） | 値をそのまま `std::filesystem::path` に渡す |
| Strata サーバー経由で未設定、設定に `log` がある | `log` の親ディレクトリにある `ds4-slots/` を子エンジン環境に設定 |
| Strata サーバー経由で未設定、`log` もない | 追加設定せず、エンジン側の pack ディレクトリ `slots/` にフォールバック |

文字列の parse、空白除去、値域検査はありません。相対パスの基準はエンジンの作業ディレクトリです。設定値が空文字なら未設定扱いにはならず、空の path でディレクトリ作成・判定を行います。ディレクトリと判定できなければ `ds4 slots: <path> is not writable - conversations are not set aside` を stderr に出し、ディスクスロットを無効にします。

## 有効になる条件

- `strata-dsv41` で会話スロット保存が有効であること。エンジン単体では `STRATA_DS4_SLOT_KEEP` が設定され、`atoi(value) != 0` となる必要があります。未設定、空文字、数値変換が 0 になる値では無効です。
- `STRATA_DS4_SLOT_CAP`（既定 4）が 1 以上であること。エンジンは `STRATA_DS4_SLOT_KEEP` が有効なとき `max(0, (int) atof(value))` を RAM 保持数にします。0 以下なら `STRATA_DS4_SLOT_DIR` を参照する初期化ブロックに入りません。
- 保存先の作成後に `is_directory` が真になること。そうでない場合はスロット保存を無効化します。

サーバー経由では `deepseek_slot_env()` が `STRATA_DS4_SLOT_KEEP=1` を `setdefault` で補います。元の環境または設定の `env` に `STRATA_DS4_SLOT_KEEP` があればその値が残ります。環境変数を含む設定 `env` は親環境をコピーした後に適用されるため、同じキーなら設定 `env` の値が shell の値を上書きします。`STRATA_DS4_SLOT_DIR` も同様に既存値が優先され、未設定時だけ `log` の隣の `ds4-slots/` が設定されます。

## 実行時の詳細

エンジンは起動時に値を読み、ディレクトリを作成して保存済みスロットを走査します。`slot-` で始まる `.meta` を読み、対応する `.bin` のサイズが一致し、メタデータが現モデルに適合し、最終更新から `STRATA_DS4_SLOT_DAYS`（既定 7 日）以内なら再利用候補にします。欠損・不一致・期限切れ・一時ファイルは削除対象です。フォルダーの上限は `STRATA_DS4_SLOT_GB` で決まり、ディスク使用量が超えたとき最も古く使われた会話から削除します。これらの処理は指定ディレクトリ内だけで行われます。

リクエスト間では、モデルから退避した会話をまず RAM に保持し、RAM 上限を超えたものを指定フォルダーに書きます。会話が続くリクエストでスロットを復元し、エンジン終了時には RAM にある会話もフォルダーへ書きます。開始時の保存済み件数、拒否・削除件数、読み戻し、書き込みなどは stderr の `ds4 slots:` と stdout の `NOTE sessions:` に出ます。パスが使用不能な場合は前述の警告後に通常のプロンプト再読み込みへ進みます。

サーバーの `child_env()` は DeepSeek-V4.1 用設定の場合にだけ slot 関連の環境を子エンジンへ加えます。サーバーの設定または親環境で `STRATA_DS4_SLOT_DIR` を指定すれば、規定のログ隣接フォルダーを差し替えられます。
