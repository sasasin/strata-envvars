# `FAKE_TOKEN_DELAY`

調査対象: Strata `main` の HEAD `4b9e05a2a806a3fe24f7b2560d98626c37dade35`（2026-10-26 時点）。

## 役割

デスクトップアプリの UI フロー検証で起動する偽エンジンが、生成トークンを1個出すごとに待つ秒数です。Strata の通常の engine やサーバーの利用者向け設定ではなく、`apps/desktop/scripts/ui-flows.mjs` が作るテスト用 `engine_main.py` のみが読みます。

## 値と判定

| 環境変数の状態 | 偽エンジンの処理 |
|---|---|
| 未設定または空文字 | sleep を呼ばず、追加遅延なし |
| 空でない文字列 | Python の `float()` で変換し、その値を秒として `time.sleep()` に渡す |
| 数値として変換できない文字列 | `float()` の `ValueError` で偽エンジン処理が失敗する |
| 負の数 | `time.sleep()` が `ValueError` を送出する |

文字列 `"0"` は Python では空文字ではないため sleep が呼ばれますが、待ち時間は0秒です。`float()` が受け付ける表記（例: 小数・指数表記）を使えます。変換結果の clamp や独自 fallback はありません。`nan` / 無限大など特殊値の実際の扱いは Python の `time.sleep()` に委ねられ、Strata 側で検査していません。

## 有効になる条件

変数を読むコードは、`FAKE_ENGINE` 文字列に埋め込まれた偽エンジンにあります。この偽エンジンは UI フローシナリオの `installed: true` のときだけ生成されるテスト用コンポーネントです。シナリオが `FAKE_TOKEN_DELAY` を設定しない場合、親プロセスから継承された値があればそれも `baseEnv` を通じて子のホストへ渡ります。したがって環境変数の値だけでは適用を保証せず、該当テスト用偽エンジンが生成要求を処理する必要があります。

## 実行時の詳細

偽エンジンは `FAKE_REPLY` の各文字について `T <コードポイント>` を標準出力へ flush し、その直後に環境変数を確認します。値が空でなければ、その都度 `float(os.environ['FAKE_TOKEN_DELAY'])` を評価して sleep します。このため一度の生成中も各トークンごとに値を読み直し、値を先読みしてキャッシュする処理はありません。環境変数を実行中に変更した場合、その後のトークンで新しい値が使われます（プロセスの環境自体を外部から変更する仕組みは本スクリプトには記述されていません）。

シナリオ `ui2` / `ui2d` と `tune` は `0.02` を、`stop` は `0.1` を設定し、UI 上で応答の逐次表示や生成停止を確認できる程度に偽応答を遅らせます。設定値が示すのはトークンごとの要求待ち時間であり、実際の総応答時間は文字数、処理時間、プロセス間通信などにも依存します。
