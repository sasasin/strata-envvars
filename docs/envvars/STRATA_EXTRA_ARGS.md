# `STRATA_EXTRA_ARGS`

調査対象: Strata `main` の HEAD `477ac13cbe8e582c20484871ce459d20d82df09d`（2026-10-17 時点）。外部ライブラリの環境変数は対象外。

## 役割

この変数は通常の Strata サーバー設定ではなく、同梱の会話キャッシュ関連テストスクリプト3本が、エンジンの起動引数へ追加オプションを渡すために使います。対象は `tools/batch_groups_cache_test.py`、`tools/session_pressure_test.py`、`tools/cancel_park_test.py` です。それぞれのスクリプトが起動する `StrataEngine` に、設定ファイル由来の引数とこの変数由来の引数を渡します。

## 値と判定

| 状態 | スクリプト内での扱い |
|---|---|
| 未設定 | `os.environ.get(..., "")` が空文字を返し、引数を追加しない |
| 明示的な空文字 | `.split()` の結果が空リストになり、引数を追加しない |
| 空白だけ | `.split()` の結果が空リストになり、引数を追加しない |
| その他の文字列 | Python の引数なし `str.split()` で空白区切りした要素を順序どおり追加する |

値の真偽、数値形式、オプション名やオプション値の妥当性は、この変数を読むスクリプトでは検査しません。シェル風の引用符・エスケープも解釈しないため、たとえば `--label "two words"` は `--label`、`"two`、`words"` の3要素になります。各要素の解釈と無効なオプションの扱いは、起動されたエンジン側のコマンドライン処理によります。

## 有効になる条件

この変数を読むのは上記3つのテスト用スクリプトです。一般のサーバー起動や Strata エンジン本体が `STRATA_EXTRA_ARGS` を参照する実装は、この HEAD のソース全体では確認できません。`tools/batch_groups_cache_test.py` は `engine_args(cfg)` の結果に追加します。他の2本は `cfg["args"]` に追加します。いずれも設定ファイル由来の引数の後ろに要素を連結します。

スクリプトは `StrataEngine` に組み立てた引数リストを渡します。サーバー実装の `child_env(cfg)` は元の `os.environ` をコピーするため、環境変数自体も子エンジンの環境には継承されますが、エンジンがこの変数を直接読む処理は確認できません。ここでの効果は Python テストスクリプトが読み取り時に起動引数へ展開することです。

## 実行時の詳細

値は各テストスクリプトのトップレベルで一度読み取られ、エンジン起動前に引数リストへ追加されます。したがって、スクリプト実行中に環境変数を書き換えても、既に組み立てた当該エンジンの引数は変わりません。スクリプト例では、バッチ・プロンプトキャッシュ・会話キャッシュの各 CLI オプションを指定します。`session_pressure_test.py` はさらに `--conversation-cache-min-free-mib` と任意の `--session-save-reclaim` を例示します。これらは使用例であり、この環境変数自体がそれらの機能を実装・有効化するわけではありません。
