## 役割

セットアップが行う大容量 HTTP(S) ダウンロードと、同梱ツール `tools/mtp_fetch.py` が行う MTP tensor の ranged download で、同時に使う接続数を指定します。Strata のエンジン実行時設定ではなく、セットアップ／準備ツール用の設定です。

## 値と判定

どちらの実装も値を `strip()` した後、空でなければ Python の `int()` に渡し、結果を 1〜32 に clamp します。文字列全体が整数として解釈できる必要があります。小数や末尾に文字が付いた値など `int()` が拒否する値は、エラーにならず既定値 16 に戻ります。符号付き整数など `int()` が受理する表記は受理されます。

| 環境変数の状態／値 | 接続数 |
|---|---:|
| unset、空文字、空白だけ | 16 |
| `1`、`+1` | 1 |
| `0`、負数 | 1（下限 clamp） |
| `2`〜`32` | 指定値 |
| `33` 以上 | 32（上限 clamp） |
| `4.0`、`abc` など整数に変換できない値 | 16 |

根拠: `setup.py:1978-1996`、`tools/mtp_fetch.py:240-246`。

## 有効になる条件

- `setup.py` の通常ダウンロードでは、HTTP(S) のファイルサイズが判明し、サイズが 256 MiB 以上で、接続数が 2 以上の場合に Range download を試します。1 以下なら単一ストリームです。小さいファイル、サイズ不明のファイル、およびローカルパス／`file://` のコピーには並列接続数は適用されません。Range に対応しないサーバーでは単一ストリームへ fallback します。
- `tools/mtp_fetch.py` は inventory の shard header 読み取りを最大 8 worker（さらに shard 数まで）に制限します。tensor fetch では接続数を worker 数として使い、1 以下なら ranged read を逐次実行します。
- この変数を別の Strata 設定、CLI オプション、設定ファイルが上書きする実装は確認できません。`STRATA_SOURCE` は MTP の取得元選択に使われますが、接続数の値判定には使われません。

根拠: `setup.py:2624-2645,2675-2694`、`tools/mtp_fetch.py:249-277,329-336,362-380`。

## 実行時の詳細

通常のセットアップは各 HTTP(S) ファイルの HEAD／サイズ確認後に `dl_connections()` を呼びます。2〜32 接続で並列化する場合、各 worker が 32 MiB 単位の piece を Range request で取得し、完了済み piece を保存して中断後に再開できるようにします。ダウンロードサーバーが Range に応答しない場合は `parallel_download()` が false を返し、呼び出し元が単一ストリーム経路に切り替えます。進捗は標準出力に表示され、再試行時は stderr に警告が出ます。

MTP fetch は通常セットアップから `fetch_mtp()` → `run()` → `subprocess.run()` で起動されます。呼び出し元は `env = dict(os.environ, ...)` を渡し、`run()` はその環境を子プロセスに渡すため、設定値は `tools/mtp_fetch.py` に継承されます。ツールは inventory と fetch の処理で `connections()` を読みます。fetch の Range chunk は worker 数が 2 以上なら 16 MiB、1 なら 64 MiB です。ネットワークエラーが起きると worker 数は `max(4, workers // 2)` に変更され、同じ tensor の再試行を続けます。そのため、初期値を `1` にしても、ネットワークエラー後の再試行では 4 worker に増える場合があります。3回を超えるネットワーク失敗では stderr にエラーを出して終了します。

どちらも値を static cache していません。セットアップは各ファイルのダウンロード開始時に読み、MTP ツールは inventory／fetch の各処理で読みます。通常の外部プロセスから起動後に親プロセスの環境を変更することはできないため、実用上は起動時の環境値が使われます。CLI や設定ファイルとの優先順位はありません。

根拠: `setup.py:747-766,769-785,1978-1996,2365-2405,2624-2694`、`tools/mtp_fetch.py:240-277,329-336,362-416`。
