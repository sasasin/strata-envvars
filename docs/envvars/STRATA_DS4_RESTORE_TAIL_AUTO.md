# `STRATA_DS4_RESTORE_TAIL_AUTO`

調査対象: Strata `main` の HEAD `ffa80d73133ea5c548aefe57889a16e8085a938f`（2026-11-03 時点）。

## 役割

`maya-ds4 --serve` が要求の `tail=<位置>` で追加 restore point を残すかを自動判定するスイッチです。既定では自動判定が有効で、tail point で読み取りを分けるコストが後続 token を読み直すコストより大きいと測定された場合、以後の要求でその点を省きます。`STRATA_DS4_RESTORE_TAIL_AUTO=0` はこの自動除外を止め、条件を満たす `tail=` を毎回 restore point 候補にします。

## 値と判定

値は `std::atoi()` で整数変換し、結果が 0 かどうかだけを見ます。文字列全体の妥当性検査はありません。

| 環境変数の状態 | `tail_auto` |
|---|---|
| 未設定 | 有効（既定） |
| `0`、`00`、空文字、数値に変換できない文字列 | 無効（`atoi` が 0） |
| 先頭の整数変換結果が 0 以外 | 有効。負数も含む |

`atoi` の変換規則により、先頭の空白や符号の後の整数部分が使われ、後続の非数値文字は判定されません（例: `1x` は有効、`0x` は無効）。

## 有効になる条件

- `--serve` を指定してモデルのロードが成功し、サーバー処理に入る必要があります。値は通常の非 serve 実行では参照されません。
- 要求が `GEN` / `GENI` の `tail=<整数>` を含み、その値が今回読み始める位置 `from` より後、かつ prompt の最後の token より前である必要があります。`tail` の値は要求行から `std::atoll()` で読み取られます。
- `m.marks_cap() > 0` が必要です。restore point 容量は `STRATA_DS4_RESTORE_POINTS`（未設定なら旧名 `DS4_RESTORE_POINTS`、どちらも未設定なら 4）で決まり、値は 0 から上限に clamp されます。容量が 0 の場合、この環境変数が有効でも tail point は計画されません。
- tail 候補は `mark_plan()` に渡された後、読み取り範囲、他の mark との間隔、容量上限、画像 span の位置などの規則を受けます。したがって `=0` は候補を自動判定で除外しない設定であり、すべての要求で point が必ず保存される保証ではありません。

この変数に対する OS / GPU backend / build macro による値判定の分岐はありません。CLI 起動引数に同じ設定を上書きする項目もありません。`tail=<位置>` はサーバー要求ごとの指定で、この環境変数はその指定を自動的に候補から外すかを制御します。

## 実行時の詳細

環境変数はモデルのロード後、`serve()` の初回実行時に関数内の `static const bool` として読み取られ、プロセス内で cache されます。serve 中に環境値を変更しても再評価されません。自動判定用の `TailCost` は serve プロセス内に保持され、要求間で計測結果を使いますが、新しいプロセスには引き継がれません。

自動モードでは、まず tail point を含む読み取りを行い、その前後の実時間と token 数を計測します。前半または tail の時間が正、tail token 数が 0 より大きく、前半 token 数が tail token 数の 4 倍を超える読み取りだけが計測値として採用されます。tail の token あたり時間を前半の token あたり時間で割った比率を使い、2 回以上の計測値の平均が 2 を超えると「高コスト」と判定します。高コストの場合は tail point を省き、32 回省いた後の候補で 1 回 point を残して再計測します。再計測によって比率が 2 以下に戻ると、その旨を stderr に出力します。

高コストで tail point を省いたときは、stderr に `ds4 serve: the tail restore point is left out on this PC: ...` を一度だけ出します。自動判定が無効の場合は tail 候補を毎回追加し、計測値の追加・自動除外・上記の自動判定ログは行いません。通常の prompt 読み取り・mark 保存経路はそのまま使われ、環境変数固有のエラーや終了経路はありません。
