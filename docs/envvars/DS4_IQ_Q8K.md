# `DS4_IQ_Q8K`

調査対象: Strata `main` の HEAD `ffa80d73133ea5c548aefe57889a16e8085a938f`（2026-11-03 時点）。

## 役割

DeepSeek-V4.1 (`strata-dsv41`) の GGUF 低ビット expert に渡す activation を、CPU lane の Q8_K 方式で量子化するか選びます。未設定または `atoi` の結果が 0 なら、従来どおり 32 要素ごとの `q8_1` 方式です。非 0 なら `k` が 256 の倍数である呼び出しに限り、256 要素単位で最大絶対値とその値の符号から scale を作る Q8_K 方式に切り替えます。Q8_K の量子化値と scale は、その後の低ビット expert の計算に渡されます。

この変数を読む実装は `src/dsv41/ds4_gguf.cu` の `iq_q8k()` だけです。同じファイル内の `iq_act_quant()` が実際の切り替えを行い、低ビット expert の gate/up、down、window 経路から呼ばれます。MXFP4 expert は従来の `q8_quant()` を直接使うため、この変数の対象外です（`src/dsv41/ds4_gguf.cu:267-276,1464-1486,1499-1517,1567-1604`）。

## 値と判定

値全体の厳密な parse や許容範囲の検査はありません。`std::atoi(v) != 0` の結果だけを使います。

| 値 | 判定 |
|---|---|
| 未設定 | 無効（既定） |
| 空文字 | 無効（`atoi` は 0） |
| 数値として 0 になる文字列（例: `0`, `false`, `abc`） | 無効 |
| `atoi` が非 0 を返す文字列（例: `1`, `-1`, `2`, `1suffix`） | 有効 |

`atoi` が先頭の空白や符号を扱い、数値の後ろを無視するため、` 1tail` も有効になります。大文字小文字の比較はありません。範囲チェック、境界値の拒否、無効文字列の警告や別値への fallback はなく、数値変換できない文字列は 0 扱いです。数値範囲外の文字列の結果は C ライブラリの `atoi` の制約に従い、このコードでは別途定義していません（`src/dsv41/ds4_gguf.cu:267-272`）。

## 有効になる条件

- `STRATA_BUILD_DSV41` で `strata-dsv41` がビルドされる経路が必要です。CMake の DSV41 ターゲットは CUDA または HIP バックエンドのブロック内にあり、`STRATA_BUILD_DSV41` が OFF なら既定では作られません。`STRATA_HIP_GFX906` の構成ではこのターゲットは作られません（`CMakeLists.txt:931-945,2930-2935`）。
- 呼び出し対象のレイヤーが MXFP4 ではなく低ビット expert である必要があります。MXFP4 では `moe_gate_up()` / `moe_down()` / `win_experts()` が `q8_quant()` を選びます。低ビット expert では `iq_act_quant()` を通ります（`src/dsv41/ds4_gguf.cu:1468-1476,1509-1517,1568-1594`）。
- 環境値が `atoi` で非 0 になり、かつ activation の長さ `k` が 256 の倍数である必要があります。`k % 256 != 0` なら設定値にかかわらず `q8_quant()` に戻ります（`src/dsv41/ds4_gguf.cu:274-276`）。
- CLI 引数、設定ファイル、または別の環境変数による上書き・優先順位の処理は、この変数の読み取り・分岐にはありません。

## 実行時の詳細

`iq_q8k()` は判定を関数内の `static const bool` に保存します。最初に同関数が呼ばれた時点の環境値がプロセス内で使われ続け、その後の環境変更では再評価されません（`src/dsv41/ds4_gguf.cu:267-273`）。

有効条件を満たすと `q8k_quant()` が各 256 要素の範囲で最大絶対値を求め、最大値の符号を使って scale を計算し、Q8_K 方式の int8 値を作ります。1 個の 256 要素 scale は 8 個の 32 要素ブロックに書かれます。それ以外は `q8_quant()` が 32 要素ごとの最大絶対値を使う方式で量子化します（`src/dsv41/ds4_gguf.cu:192-212,214-264,274-276`）。

この変数専用のログや警告、無効値エラー、終了経路はありません。カーネル起動後のエラーが検出された場合は既存の `check()` 経由で `ds4 gguf <処理名>: <CUDA error>` が stderr に出力されますが、値の判定自体がエラーを出すことはありません（`src/dsv41/ds4_gguf.cu:34-39,1475-1478,1543,1627`）。
