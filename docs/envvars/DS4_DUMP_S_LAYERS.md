# `DS4_DUMP_S_LAYERS`

調査対象: Strata `main` の HEAD `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`（2026-11-01 時点）。

## 役割

DeepSeek-V4.1 エンジンの中間データ dump で、記録する layer 番号を選びます。この変数だけでは dump は開始しません。`DS4_DUMP_S` に出力ファイル名が設定され、そのファイルを開けた場合に限り、選択 layer のサブステップを記録します。これは通常の `strata` 実行経路ではなく、別実行ファイル `strata-dsv41` にある診断用機能です。CMake の `STRATA_BUILD_DSV41` は既定 OFF です。

## 値と判定

`DS4_DUMP_S_LAYERS` の文字列をカンマで区切り、各非空要素を `std::atoi` に渡して整数 layer 番号のリストにします。名前付きの値や全体の形式検証はありません。

| 設定 | 判定結果 |
|---|---|
| 未設定 | `0,1,2,3` を使う |
| 空文字 | 空リストになり、どの layer も選ばれない |
| `2,4` | `2` と `4` を選ぶ |
| `1,,3,` | 空要素を飛ばし、`1` と `3` を選ぶ |
| `x,2tail` | `atoi` の結果である `0` と `2` を選ぶ |
| `-1,999` | 負数もそのまま保持する。通常の非負 layer 番号とは一致しないため `-1` は選択に使われない。存在しない番号も dump 呼び出しに一致しない |

空白や符号を含む要素も `atoi` の変換規則に従い、先頭の整数部分が使われます。数値として解釈できない先頭なら 0 になります。重複番号は除去されません。コードに範囲 clamp や無効値エラー処理はありません。

## 有効になる条件

- `STRATA_BUILD_DSV41=ON` で `strata-dsv41` をビルドして、その実行経路を使う必要があります。CMake ではこのオプションは既定 OFF です。
- `DS4_DUMP_S` が設定され、指定値を出力先として `fopen(..., "wb")` できる必要があります。`DS4_DUMP_S` が未設定、またはファイルを開けず `dump_s` が null の場合、layer 選択結果にかかわらず記録しません。`DS4_DUMP_S_LAYERS` 自体はファイルを作りません。
- エンジンの window 経路および chunk 経路にある `dump_sub` / `dump_sub_host` 呼び出しが、選択 layer について実行されたときに記録します。chunk 経路では一部の中間値の dump が `kv_only` 等の分岐により通らない場合があります。
- CLI 引数や別の環境変数が `DS4_DUMP_S_LAYERS` を上書きする処理は確認できません。`DS4_DUMP_S_NAMES` は記録する中間点名をさらに絞る別の条件です。

## 実行時の詳細

値は `ds4_model.cu` の `Impl` メンバー初期化時に読み、インスタンスごとに一度 vector へ保存します。実行中の環境変更は既存インスタンスに反映されません。未設定時の既定値 `0,1,2,3` を使う場合も、`DS4_DUMP_S` が有効でなければ出力しません。

選択 layer の中間値は `dump_sub` から GPU→host コピーされるか、すでに host にある値は `dump_sub_host` に渡されます。各レコードは `char name[16]`、`int64` 4 個（layer、`p0`、`T`、byte 数）、続いて raw bytes です。書き込み後に `fflush` します。書き込みやファイル open の失敗を報告する専用ログ、fallback、終了処理はこの箇所にはありません。dump 記録箇所ではコピーと stream 同期を行うため、条件成立時は診断 I/O が実行経路に入ります。
