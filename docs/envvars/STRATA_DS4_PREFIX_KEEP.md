# `STRATA_DS4_PREFIX_KEEP`

調査対象: Strata `main` の HEAD `ffa80d73133ea5c548aefe57889a16e8085a938f`（2026-11-03 時点）。外部ライブラリの環境変数は対象外。

## 役割

`strata-dsv41 --serve` が、会話間で再利用する共有プロンプト先頭のモデル状態を RAM に何件まで保持するかを指定します。プロンプトの共有開始点を一度読み終えたとき、その状態と token 列を別途保存し、後のリクエストで同じ token 列を含むプロンプトが来れば、保存状態を復元して先頭の再読を省きます。既定値は 2 件です。これは会話全体を保持する `STRATA_DS4_SLOT_KEEP` とは別の共有開始点キャッシュです。

## 値と判定

| 環境変数の状態・値 | 処理 |
|---|---|
| 未設定 | 既定値 `2` を使う |
| 空文字、数値として始まらない文字列 | `std::atof` の変換結果 `0`。保持件数は 0 になる |
| 数値文字列 | `std::atof` で `double` に変換し、`int` にキャストして小数部を落とした後、`max(0, 値)` を適用 |
| 負数または 0 | 0 件 |
| 正の小数 | 小数部を落とした整数件数。たとえば `2.9` は 2 件 |
| 数値の後ろに文字がある値 | `atof` が数値部分を変換するため、たとえば `2abc` は 2 件 |

全体が数値であることの検証や、変換エラーの警告はありません。空文字や数値として読めない値は例外にならず 0 として扱われます。`int` への変換前に範囲検査をするコードはありません。

## 有効になる条件

- DS4 の `--serve` 経路でのみ読み取られます。`main()` はモデルのロード後、`serve_mode` の場合に `serve()` を呼び出します。
- モデルの restore point 上限 `m.marks_cap()` が 0 より大きい必要があります。これは `STRATA_DS4_RESTORE_POINTS`（未設定時は `DS4_RESTORE_POINTS`、それも未設定なら 4）で決まり、結果はモデル内で一度 static cache されます。上限を 0 にすると `prefix_max` も 0 になり、共有開始点は保持されません。
- 保持対象になるのは、要求の `shared=` / `pin=` などから作られた共有 restore point に到達し、先頭 token からの読み取りで、対象の prefix が `STRATA_DS4_PREFIX_MIN` 以上かつ画像を含まない場合です。画像付きの開始点は保存されません。
- `STRATA_DS4_PREFIX_GB` は保存 byte 数の予算、`STRATA_DS4_PREFIX_MIN` は保存する最小 token 数を制限します。件数値だけを満たしても、これらの条件で保存されないことがあります。
- `STRATA_DS4_PREFIX_STOP` が設定されているかどうかで共有開始点で読み取りを止める経路が変わります。未設定時は読み取りを続ける経路でも共有開始点の状態を別に保存し、設定時は共有開始点で止めます。どちらも `prefix_max` が正であることが前提です。

## 実行時の詳細

設定値は `serve()` の開始時に一度読み、ローカル定数 `prefix_max` に保持します。リクエストごとの再読やプロセス内での再評価はありません。共有開始点の状態は `m.slot_save()` で RAM に保存し、token 列とともに vector に入れます。キャッシュが上限を超えた場合は、使用時刻が最も古い項目から削除します。保存後のログは stderr に `ds4: kept a ... token shared start ...`、再利用時は `ds4: took back a ... token shared start ...` と出ます。保存または復元に失敗した場合は stderr に失敗理由を出し、復元失敗時は項目を削除してプロンプトを読み直します。

値が 0 の場合は `prefix_keep()` が早期 return し、`prefix_find()` が調べる保存項目もなく、共有開始点の再利用は起きません。CLI 引数による上書き経路はありません。
