# `DS4_AHEAD`

調査対象: Strata `main` の HEAD `4b9e05a2a806a3fe24f7b2560d98626c37dade35`（2026-10-26 時点）。外部ライブラリの環境変数は対象外。

## 役割

DeepSeek-V4.1 の DS4.1 実装で、現在層を計算している間に後続層の expert 選択を推測し、その expert のファイルページを先にページキャッシュへ読み込む lookahead を制御します。予測結果は後続層で実際に選ばれた expert を変えず、コードコメントはページキャッシュだけを先行させ、出力は同じと説明しています。値を正数にすると 1 層先を予測し、2 以上なら 2 層先まで予測します。

## 値と判定

値は `std::atoi` で整数化され、設定文字列全体の検証はありません。

| 状態・値 | 動作 |
|---|---|
| 未設定 | 通常は `ahead_mode=1`。ただし `--ssd-cache` の RAM store を初期化する経路では 0 に変更される。 |
| 空文字 | `atoi("")` は 0 となり、lookahead を無効にする。 |
| 整数として 0 または負数 | 先読みスレッドを作らず、予測・先読みを行わない。 |
| 正数 1 | 1 層先を予測する。 |
| 正数 2 以上 | 1 層先と 2 層先を予測する。2 を超えても対象層数は増えない。 |
| 数字で始まらない文字列 | `atoi` の結果が 0 となり、無効。 |
| 数字の後ろに文字が続く文字列 | 数字の先頭部分を変換する。例: `2abc` は 2 として扱う。 |

`atoi` のため、先頭空白と符号を含む整数表記も変換されます。値域の明示的な clamp はありませんが、予測ループは `min(2, ahead_mode)` までに制限されています。根拠: `src/dsv41/ds4_model.cu:988-997,2793,9059-9068`。

## 有効になる条件

正数を設定しても、すべての層で予測できるわけではありません。予測対象の後続層は、同じ device と同じ MTP 区分にあり、形式が MXFP4、router の gate weights が存在し、expert 数が 1024 以下で、slot 情報が揃っている必要があります。また、その層にファイルから読む expert が少なくとも一つなければ対象になりません。条件に合わない場合、その層の予測処理は行われません。根拠: `src/dsv41/ds4_model.cu:6394-6409`。

RAM store（`--ssd-cache`）を使う経路では、環境変数が未設定なら lookahead は無効化されます。明示設定があるとこの上書きは行われず、正数なら有効化できます。lookahead 要求時、store があれば `store->prefetch()` に expert を渡し、store がなければ各 expert の MXFP4 ファイル部分をページ先読みキューへ送ります。根拠: `src/dsv41/ds4_model.cu:4710-4719,6411-6447`。

## 実行時の詳細

環境変数は DS4.1 の model/state オブジェクト初期化時に読み取られ、`ahead_mode` に保存されます。起動時の値を保持するため、その後プロセス内で環境を書き換えても既存オブジェクトの値には反映されません。初期化時に `ahead_mode > 0` なら専用 prefetch thread を開始します。各層の GPU 処理では現在層の入力から後続層の gate を計算し、候補 expert を request に載せます。CPU lane がその request を受け取ると、ファイルにある未常駐 expert の範囲を先読み thread または RAM store に依頼します。先読み thread は `os::prefetch_cold()` を実行します。根拠: `src/dsv41/ds4_model.cu:994,2782-2793,6380-6392,6411-6447,9051-9072`。

`DS4_AHEAD_EXTRA` は 1 層先の予測候補数を調整しますが、`DS4_AHEAD` とは別の環境変数です。1 層先の候補数は `max(1, min(kAhead1, nx->k_exp + ahead_extra))`、2 層先は `min(kPicks, nx->k_exp)` です。予測が有効でも、候補数や対象層の条件によって実際にキューへ送るページがない場合があります。根拠: `src/dsv41/ds4_model.cu:995,6416-6439,9059-9068`。
