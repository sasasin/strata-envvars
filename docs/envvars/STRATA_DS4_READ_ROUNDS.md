# `STRATA_DS4_READ_ROUNDS`

調査対象: Strata `main` の HEAD `ffa80d73133ea5c548aefe57889a16e8085a938f`（2026-11-03 時点）。外部ライブラリの環境変数は対象外。

## 役割

`strata-dsv41` の `--serve` 複数会話モードで、prompt を分割して読み込んでいる間に、回答側を何ラウンド進めてから次の prompt 片へ切り替えるかを指定します。値が大きいほど、次の prompt 片を読む前に回答をより多く進める設定です。prompt の分割読み込みそのものを有効にする変数ではありません。

## 値と判定

値は `std::getenv()` で取得し、`std::atoi()` で整数に変換します。変換結果が正ならその値を採用し、それ以外は既定値 `1` を使います。文字列全体の数値検査や上限 clamp はありません。

| 設定値 | 結果 |
|---|---|
| 未設定 | `1` |
| 空文字、非数値、`0`、負数 | `atoi` の結果が正でないため `1` |
| 正の整数（例 `3`） | `3` |
| 数字の後ろに文字がある値（例 `3x`） | `atoi` が先頭の整数部分を変換し、`3` |

`atoi` が読む先頭の空白や符号も変換に従います。`int` の範囲を超える文字列については、このコードに範囲検査がなく、動作を保証できません。値に `1` を指定しても機能を有効化する意味にはならず、未設定時も同じ `1` です。

根拠: `src/dsv41/ds4_main.cpp:1532-1541`。

## 有効になる条件

- 対象の `strata-dsv41` 実行ファイルを含むビルドが必要です。CMake の `STRATA_BUILD_DSV41` は既定 `OFF` で、有効時に `strata-dsv41` を定義します（`CMakeLists.txt:931-945`）。
- `--serve` のときにだけ `serve(m, ...)` が呼ばれます。複数会話 scheduler はモデルの sequence 数が 1 より大きい場合に限って動きます。`--parallel` は 1〜8 を受け付け、複数会話数を設定します（`src/dsv41/ds4_main.cpp:1355-1356,2582-2588,2621-2629`）。
- 実際に読み込み片の間へ回答ラウンドを挟むには、別変数 `STRATA_DS4_READ_PIECES` が正の値に変換され、かつ `m.prompt_chunk() > 0` である必要があります。値の既定値は `0` なので、通常は分割読み込みが無効です（`src/dsv41/ds4_main.cpp:1532-1540`）。
- `GENI` による画像を含む prompt は分割対象外で、prompt 全体をその場で読みます。その間、この設定による片ごとの切替は行われません（`src/dsv41/ds4_main.cpp:1851-1859`）。
- 分割読み込みが有効でも、回答が進行中でないときは scheduler は待ちラウンドを要求せず次の片を読みます。prompt の読み込み片が待機していない場合にも、この値による切替は起きません（`src/dsv41/ds4_main.cpp:1896-1914`）。

この変数に対応する CLI 引数はありません。`--parallel` は scheduler の実行条件、`STRATA_DS4_READ_PIECES` は prompt 分割の条件であり、`STRATA_DS4_READ_ROUNDS` の値を上書きするものではありません。

## 実行時の詳細

値は `serve()` の複数会話分岐に入ったとき、ローカル `const int` に一度読み込まれます。従って、同じ `serve()` 実行中に環境値を変更しても再評価されません（`src/dsv41/ds4_main.cpp:1503-1504,1532-1542`）。

分割読み込みが動作中、scheduler は回答ラウンド数 `rounds` を数えます。回答が進行中で読み込み待ちの片があり、`rounds >= read_rounds` になると次の片を読み、カウンターを 0 に戻します。それ以外で回答があれば回答ラウンドを実行してカウンターを増やします。従って既定の `1` は回答ラウンド 1 回ごとに読み込み片へ切り替える動作です（`src/dsv41/ds4_main.cpp:1781-1795,1886-1914`）。一度に読む片の大きさは `STRATA_DS4_READ_PIECE` と `prompt_chunk()`、pipeline stage 数で決まり、この変数は片の大きさを変えません（同 `1538-1541`）。

環境変数専用のログ、警告、終了・失敗分岐はありません。通常の `T` / `DONE` 等の serve protocol 出力と prompt・生成の計測ログは scheduler によって出力されますが、コードに `STRATA_DS4_READ_ROUNDS` の値を表示する処理はありません（同 `1607-1635,1571-1583`）。この値が変えるのは prompt 読み込みと回答のスケジュール間隔です。
