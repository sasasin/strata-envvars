# `DS4_SPEC_Q`

調査対象: Strata `main` の HEAD `4b9e05a2a806a3fe24f7b2560d98626c37dade35`（2026-10-26 時点）。

## 役割

DeepSeek-V4.1 の GPU プロンプト処理で、次に処理する層の CPU 側 expert を「先読み候補」に加えるための確率しきい値です。候補 expert がこのプロンプト内で少なくとも一度選ばれると見積もる確率が `DS4_SPEC_Q` 以上なら、実際のルーティング結果が分かる前に読み込みを開始します。これは通常の `strata` エンジン全体の設定ではなく、別実行ファイル `strata-dsv41` のプロンプト用 expert streaming 経路の設定です。

## 値と判定

値は `std::atof` で `double` に変換されます。文字列全体の妥当性検査、範囲制限、無効値の警告はありません。`atof` が変換できない文字列は `0` として扱われ、数値の後ろに変換できない文字が続く場合は数値部分が使われます。

| 環境変数 | しきい値 |
|---|---:|
| 未設定 | `0.9` |
| 空文字 | `0` |
| 数値として変換できない文字列 | `0` |
| 数値文字列 | `atof` が返す値。そのまま使われ、clamp されない |

候補確率 `q` は `0` から `1` の範囲で計算され、候補条件は `q >= DS4_SPEC_Q && DS4_SPEC_Q <= 1.0` です。そのため、`1` を超える値では候補は一つも追加されません。`0` 以下の値では、確率が `0` の expert も含め、CPU 側 expert が候補になります。`NaN` 相当の入力では比較が成立せず候補は追加されません。設定値を真偽値として解釈する処理ではありません。

## 有効になる条件

- `STRATA_BUILD_DSV41=ON` でビルドする別実行ファイル `strata-dsv41` のコードに属します。この CMake オプションは既定で OFF です。
- そのモデル実行で CPU 側 expert を含む GPU prompt chunk/flow 経路が選ばれ、`flow_spec()` が呼ばれる必要があります。
- flow の初期化は `DS4_FLOW` が未設定または `atoi` の結果が非ゼロの場合に許可されます。`DS4_FLOW=0`（および `atoi` が 0 になる値）では無効です。
- 関連する各 trunk layer の expert 格納形式は MXFP4 である必要があります。Tensor-parallel group ではさらに `DS4_FLOW_TP` が非ゼロであり、down matrix の分割幅が expert type の block 幅で割り切れる必要があります。
- flow が有効でも、VRAM 内の expert は `host_list` に入らず、このしきい値による先読み候補にはなりません。対象は CPU 側の expert です。
- `DS4_SPEC_WASTE` は、過去の先読み候補の未使用率に応じて早期読み込みを続けるかを決める別の条件です。候補数がリング容量の2倍に達するまでは未使用率にかかわらず早期読み込みを行い、その後は未使用率が同変数の値を超えると早期読み込みを止めます。早期読み込みが止まっている間は `DS4_SPEC_Q` による候補選別も実行されません。

## 実行時の詳細

`flow_spec()` は層の CPU 側 expert について `p = prof[e] / sum(prof)` を求めます。`T` 行分で選択される回数の見積もり `picks = k_exp * T` を使い、少なくとも一度選ばれる確率を `q = 1 - (1 - p)^picks` として計算します（`p >= 1` は `q=1`）。`q >= DS4_SPEC_Q` の expert を `q` の降順で並べ、最大 `c.S + c.ring_n` 件までに絞ります。その候補を先に読み込みキューへ追加し、実際に選ばれた expert は後続の `flow_rest()` で追加します。候補のうち選ばれなかったものも先読み自体は実行済みとなるため、未使用読み込みが発生し得ます。

この変数の値は `flow_spec()` 内の `static const double` として初回呼び出し時に一度だけ読み込まれます。同じプロセスで環境変数を後から変更しても再評価されません。CLI 引数や設定ファイルによる上書きは、このコードにはありません。

この変数単独のログはありません。`--verbose` または `DS4_FLOW_STATS` が設定されていると、flow の統計行に先読み候補数と未選択数が表示されます。実装文字列は `... likely ones queued early; ... of them unpicked ...` です。`DS4_SPEC_Q` による速度・品質の測定値は、参照した Strata 資料では確認できませんでした。
