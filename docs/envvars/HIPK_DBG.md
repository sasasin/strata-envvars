# `HIPK_DBG`

調査対象: Strata `main` の HEAD `4b9e05a2a806a3fe24f7b2560d98626c37dade35`（2026-10-26 時点）。

## 役割

HIP 向け DSV41 IQ 行列コアカーネルの開発・診断用フラグです。通常の推論結果を保つための設定ではありません。共有メモリに重みを置くカーネルでは、重みデコードの置き換え、行列積の停止、重みの先読み停止を個別に切り替えます。レジスタに重みを置く別カーネルでは値を読み取ってカーネル引数に渡しますが、そのカーネル内では値を使いません。

## 値と判定

設定値は `std::atoi` で整数に変換され、文字列全体の検証はありません。unset は `0`、空文字や数字で始まらない文字列も `atoi` の結果が `0` となります。先頭の空白と符号の後にある数字列を読み、数字列の後ろは無視します（例: `2junk` は `2`、`-1` は `-1`）。

| 変換後の整数 | 共有メモリ重みカーネルでの効果 |
|---|---|
| `value & 1` が非ゼロ | WMMA の積和を行わず、ゼロ初期化された accumulator を出力する |
| `value & 2` が非ゼロ | IQ 重みデコーダーを呼ばず、各スレッド番号から作った値と単位 scale を代入する |
| `value & 4` が非ゼロ | キャッシュ先読み用の `touch()` を早期 return させる。通常の重み fetch/decode は続く |
| その他 | 上記フラグを組み合わせて適用する。該当ビットがなければ通常処理 |

たとえば `1`, `2`, `4`, `7` はそれぞれ対応するビット、または3ビットすべてを有効にします。フラグの組み合わせは排他的ではありません。ビット1で accumulator がゼロのままでも出力書き込みは行われ、gate/up 側では `swiglu` の結果が書かれます。

## 有効になる条件

- `STRATA_USE_HIP` でコンパイルされた `src/dsv41/ds4_iq.cu` の HIP 経路でのみ読み取られます。CUDA ビルドではこの HIP 実装は使用されません。
- `hipk::launch()` が対象にするのは `kTypes<T>` に列挙された IQ 型で、デバイス判定が通り、`a.max_rows > 16`、K/N と leading dimension の倍数条件、入力ポインターの16-byte alignmentを満たす場合です。対象外なら呼び出し元の通常カーネルに進み、`HIPK_DBG` はこの計算に作用しません。
- 共有メモリ重みカーネルが選ばれるのは `STRATA_DS4_HIPK` の整数変換結果が `2` のときです。gfx11 ではその値の場合に `hipk::launch()` が `false` を返すため、このカーネルは使われません。したがって `HIPK_DBG` の3つのフラグ効果が実行されるのは、適格な gfx12 HIP 経路で `STRATA_DS4_HIPK=2` が選ばれた場合です。
- `STRATA_DS4_HIPK` が `2` 以外ならレジスタ重みカーネルを選択します。この経路でも `HIPK_DBG` を読む箇所がありますが、カーネル本体には `dbg` の参照がなく、結果を変えません。

## 実行時の詳細

共有メモリ重みカーネルを起動する `run<T, GU, BM, BN, WM, WN>()` は、`HIPK_DBG` を関数テンプレート特殊化ごとの `static const int` に初回実行時に保存し、その値をカーネル引数に渡します。レジスタ重みカーネルの `runr<T, GU, BM, NW, NTW>()` も同様に値を読み取って引数に渡します。したがって、プロセス起動時に一律評価されるのではなく、各特殊化が初めて呼ばれた時点で固定されます。その特殊化の初回呼び出し後に環境を変更しても、その後の呼び出しには反映されません。まだ呼ばれていない別特殊化では初回呼び出し時の値が使われます。

この変数による stdout/stderr の出力、警告、エラー処理はありません。ビット1と2は計算データまたは計算結果を変えるため、通常の推論品質や出力を評価する目的の値ではありません。
