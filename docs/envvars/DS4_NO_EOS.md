# `DS4_NO_EOS`

調査対象: Strata `main` の HEAD `4b9e05a2a806a3fe24f7b2560d98626c37dade35`（2026-10-26 時点）。

## 役割

DeepSeek V4.1 用の同梱 CLI `maya-ds4` の単独生成で、生成 token の ID が `1` になったときに終了する動作を抑止します。設定すると ID `1` が出ても生成を続け、`--n` で指定された token 数に達した時点で終了します。この変数はサーバーの `--serve` モード全体を制御する設定ではありません。

## 値と判定

値の内容は parse せず、`std::getenv("DS4_NO_EOS") == nullptr` かどうかだけを調べます。

| 環境変数 | token ID `1` の扱い |
|---|---|
| 未設定 | 終了条件になる |
| 設定あり（空文字、`0`、`false` を含む任意の値） | 終了条件にならず、生成を続ける |

ただし、どちらの場合も `out.size() >= n` になれば終了します。したがって `--n` は上限として残ります。`--n` 自体は `std::atoi` で読み取られ、通常の生成ループへ入るのは `n > 0` の場合です。

## 有効になる条件

この判定があるのは `src/dsv41/ds4_main.cpp` の ID 列を与えた単独生成経路です。`--serve` はこのループの前に `serve(...)` へ分岐して戻り、`--score`、`--spec-eval`、`--profile` もそれぞれ別の処理へ先に戻るため、この判定は適用されません。画像エンコード専用経路も生成ループを通りません。

## 実行時の詳細

プロンプトを feed した後、`n > 0` なら最初の token を sample し、各ループで token を出力・記録してから終了条件を評価します。token ID が `1` かつ `DS4_NO_EOS` が未設定ならその場で停止します。変数が設定されていて ID `1` が出た場合は、通常の decode round を進めます。値はループ中の終了条件評価ごとに `getenv` で読み直され、`static` 変数への保存はありません。

生成 token は stdout にカンマ区切りで出力され、ループ終了後に改行されます。この変数専用のログや警告はありません。
