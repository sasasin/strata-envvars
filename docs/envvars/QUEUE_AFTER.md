# `QUEUE_AFTER`

調査対象: Strata `main` の HEAD `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`（2026-11-01 時点）。

## 役割

同梱の HTTP 診断スクリプト `apps/host/scripts/agent-http.mjs` の `plan` コマンドで、任意の追加メッセージをチャットのキューへ送るまでの待ち時間を秒で指定します。Strata の通常の起動やモデル推論設定を変更する変数ではありません。スクリプトは、計画を goal として開始した後、実行中の `plan-step` フレームを受け取るとタイマーを設定し、満了時に `/api/chat/queue` へメッセージを POST します（`apps/host/scripts/agent-http.mjs:144-162`）。

## 値と判定

値は `Number(process.env.QUEUE_AFTER ?? 8) * 1000` で数値に変換され、`setTimeout` にミリ秒で渡されます。環境変数は文字列全体の数値変換であり、接頭辞だけを読む処理や明示的な範囲検査はありません。

| 状態・値 | スクリプトが行う処理 |
|---|---|
| 未設定 | `?? 8` により既定値 8 秒を使う。 |
| 空文字 | 空文字は nullish ではないため既定値に置き換わらず、`Number("")` を掛けた値をタイマーへ渡す（0 秒）。 |
| 数値として読める文字列 | `Number` の結果を秒として 1000 倍し、タイマーへ渡す。小数も丸めずに渡す。 |
| 数値として読めない文字列 | `Number` の結果（`NaN`）を検査・補正せず、そのまま 1000 倍してタイマーへ渡す。 |
| 負値、非常に大きい値 | 範囲制限、clamp、エラー処理をせず、変換結果をそのままタイマーへ渡す。 |

タイマーの非有限値・負値・上限値に対する実際の発火時刻は Node.js のタイマー実装に委ねられ、このスクリプト内に独自の規則はありません（`apps/host/scripts/agent-http.mjs:160`）。

## 有効になる条件

- `node scripts/agent-http.mjs plan "タスク" "キューに入れるメッセージ"` のように `plan` コマンドを選び、2 番目の位置引数 `queued` が truthy であること。空文字のメッセージでは `if (queued ...)` に入らず、この変数も読まれません（`apps/host/scripts/agent-http.mjs:144-148,159-160`）。
- `/plan` の応答に `plan` フレームがなければスクリプトは `NO PLAN FRAME ...` を出して終了コード 1 となり、環境変数を読む開始処理へ進みません（同:150-152）。
- `STOP_AT_PLAN` が設定されている場合は開始前に指定された plan 操作を行い、終了コード 0 で終了するため、キュー送信タイマーは設定されません（同:155-157）。
- 開始後に `type === 'plan-step'` かつ `state === 'running'` のフレームを受け取った時だけタイマーを設定します。`sent` を先に `true` にするため、このスクリプト実行中に対象となるのは最初の該当フレームだけです（同:158-161）。

## 実行時の詳細

この値はスクリプトのプロセス内で、上記条件が成立した時に読み取られ、数値変換後の遅延が一度タイマーへ渡されます。モジュール読込時のキャッシュや再読み取りループはありません。タイマー設定後の環境変数変更は、すでに渡した遅延には反映されません。コマンドライン引数はキューに入れるメッセージの有無を決めますが、待ち時間は `QUEUE_AFTER`（未設定なら 8 秒）が決めます（`apps/host/scripts/agent-http.mjs:146-160`）。

タイマー満了後、スクリプトは同じチャット ID と `queued` メッセージを `/api/chat/queue` に POST し、成功時は返された message を `-- queue` とともに標準出力へ表示します。要求が失敗すると `j()` が HTTP ステータスと応答エラーを含む例外を投げ、タイマーの catch が `queue failed: <エラー>` を標準出力へ出します（`apps/host/scripts/agent-http.mjs:18-23,160`）。サーバー側はキュー受付時に goal が動作中でない場合は 409、その他の受付エラーは 400 を返し、受理条件の詳細は `apps/host/server/index.mjs:1910-1915` と `apps/host/server/agent/agent-bridge.mjs:1102-1114` にあります。
