# `PLE_EXPECT_FORMAT`

調査対象: Strata `main` の HEAD `4b9e05a2a806a3fe24f7b2560d98626c37dade35`（2026-10-26 時点）。

## 役割

PLE FP8 parity 診断プログラム `ple_fp8_parity` が、開いた PLE テーブルの形式名を期待値と照合するための環境変数です。実行時エンジンの PLE 形式を選択・変更する設定ではありません。

## 値と判定

`getenv("PLE_EXPECT_FORMAT")` が未設定なら、期待値は大文字小文字を含めて完全一致する文字列 `F8_E4M3` です。設定されている場合は、値全体を変換せず、その文字列を期待値として `strcmp` で形式名と比較します。

| 環境変数 | 期待値 | 照合結果 |
|---|---|---|
| 未設定 | `F8_E4M3` | テーブル形式名が `F8_E4M3` と完全一致すれば一致 |
| `F8_E4M3` | `F8_E4M3` | 完全一致すれば一致 |
| 空文字 | 空文字 | 通常の形式名とは一致せず、不一致 |
| その他の文字列 | 設定値そのもの | 完全一致しない場合は不一致。大文字小文字、前後の空白も区別 |

数値変換や値域検査、設定値の fallback はありません。各比較で不一致なら `bad` に 1 が加算されます。

## 有効になる条件

この変数を読むのは `src/kernels/ple_fp8_parity.cpp` のみです。同実行ファイルは `STRATA_ENABLE_CUDA` と `STRATA_BUILD_TESTS` が有効な場合に CMake で追加されます。したがって、通常の Strata 実行ファイルや HIP 専用ビルドでは、このコードによる参照はありません。

## 実行時の詳細

`ple_fp8_parity <ple-fp8.gguf> <reference.bin> [<iq4nl shard.gguf>]` は、PLE テーブルを Direct と Mmap の各 I/O モードで開きます。それぞれのモードで `t.format()` を環境変数由来の期待値と比較します。変数は各モードの比較時に読み取られ、static cache されません（プログラム自身が環境を書き換える処理はありません）。

形式名の不一致は、行データの差異や `gather_batch` の失敗と同じ `bad` カウンターへ加算されます。処理後に `RESULT: MISMATCH` を表示して終了コード 1 を返し、一致して他の検査にも失敗がなければ `RESULT: FP8 rows exact` と終了コード 0 を返します。プログラムの引数不足やテーブルを開けない場合は、それぞれ別の早期終了経路です。

このチェックは形式を設定せず、すでに開いたテーブルの形式名を検証するだけです。PLE テーブルの形式選択は別実装であり、この環境変数がその選択へ作用する根拠は見つかりません。
