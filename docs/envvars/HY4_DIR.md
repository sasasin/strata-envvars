# `HY4_DIR`

調査対象: Strata `main` の HEAD `73d4f4196c25a65e02f6b9ef25d354826ce55105`（`2026-11-23` 時点）。

## 役割

`HY4_DIR` は Metal 版 Hy4-Flash 用の開発ビルドスクリプト `engine/src/hy4flash/metal/build_mac.sh` が、作業ツリーと生成物のルートを指定するために読む。実行時エンジンの設定ではない。未設定または空文字なら `$HOME/strata-mac/hy4` を使い、その下の `wt/engine` をソースルート、`bin` を出力先にする。値を変えると同スクリプトのコンパイル入力と生成ファイルの場所が変わる（`engine/src/hy4flash/metal/build_mac.sh:5-13, 35-47`）。

## 値と判定

| 条件 | unset | 有効になる値 | 無効になる値 |
|---|---|---|---|
| `build_mac.sh` 実行時 | `$HOME/strata-mac/hy4` | 空でない任意の文字列をルートパスとして使用 | 値の形式検査はなく、環境変数として無効と判定される文字列はない |

`${HY4_DIR:-...}` は未設定と空文字の両方で既定値に置き換える。非空値は比較・数値変換せず、そのまま `H` に代入する。`0`、`false`、`true`、`0anything` もすべて指定パスとして扱う。前後の空白、大文字小文字、パスの存在確認を環境変数自体に対して検証しない（`engine/src/hy4flash/metal/build_mac.sh:5`）。`H` から `S=$H/wt/engine` と `O=$H/bin` を作り、以後それらを非引用のパス展開で使うため、空白や glob 文字を含む値は単一のパスとして保護されない（同:6-13, 18-47）。相対値はスクリプトを起動した作業ディレクトリからの相対パスとなる。

## 有効になる条件

- `engine/src/hy4flash/metal/build_mac.sh` を実行した場合だけ参照される。Strata の通常のランタイムやサーバーの環境設定として読む箇所は見つからなかった（同:1-5。対象リポジトリでの名前の全参照は同ファイル 5 行目のみ）。
- スクリプトは `clang++` と Apple の `Metal` / `Foundation` framework を使うビルド用で、コメントでは macOS と Command Line Tools の利用を想定している（同:2, 15, 18-47）。ただし、環境変数の読み取り自体に OS 判定はない。
- 位置引数 `$1` はビルド対象（省略時 `all`）を決める別の入力であり、`HY4_DIR` の値を上書きしない（同:16-18, 20-35, 49-65）。対象指定で該当ビルド節を通らない場合でも、冒頭で `H` / `S` / `O` を設定し、`mkdir -p $O` を実行する（同:5-8）。
- 指定先がビルドに必要なソースを含まない場合や、ディレクトリ作成・コンパイル・生成コマンドが失敗した場合、スクリプトは処理を完了できない。`set -e` により失敗したコマンドで終了し、最後の `build done` は出ない（同:4, 8-13, 47-66）。

## 実行時の詳細

スクリプト開始直後に一度だけシェル展開して `H` に代入し、`S` と `O` を導出する。以降に親環境の値が変わっても、この実行中の代入値は再評価されない（`engine/src/hy4flash/metal/build_mac.sh:4-8`）。

`O` は `bin` とその下の `zstd`、`gen`、`cpu` 等のオブジェクト・生成ソース・実行ファイルの出力先に使われ、`S` はコンパイル対象の `engine` ツリーを指す（同:8-13, 18-64）。`HY4_DIR` 自体を子プロセスに引き渡す処理はない。コンパイラや Python へのパスはスクリプトが引数として展開して渡す。環境変数の変更によるビルド結果の内容差はこのスクリプトからは規定されず、確認できるのは入力・出力パスの変更である。

## ログと測定値

正常に最後まで実行すると標準出力へ `build done` を出す。`set -e` の対象コマンドが失敗すれば途中終了するため、このメッセージには到達しない。`HY4_DIR` の値そのものを表示するログや、変数専用の警告・エラー処理はない（`engine/src/hy4flash/metal/build_mac.sh:4, 66`）。この変数についての測定値は該当しない。
