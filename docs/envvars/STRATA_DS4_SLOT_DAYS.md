# `STRATA_DS4_SLOT_DAYS`

調査対象: Strata `main` の HEAD `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`（2026-11-01 時点）。

## 役割

`strata-dsv41` の会話 slot 機能が、前回の実行から slot フォルダーに残っている会話を何日まで再利用候補として受け入れるかを指定します。`--serve` 経路でのみ読み取られます。`STRATA_DS4_SLOT_KEEP` が有効で slot フォルダーの初期走査が行われるとき、meta ファイルの最終更新時刻から求めた経過日数がこの値以下の slot を候補にします。古い slot は `.meta` と対応する `.bin` が削除されます。

## 値と判定

読み取りは `env_num("STRATA_DS4_SLOT_DAYS", 7)` で行われます。helper は変数が未設定なら既定値を返し、設定されていれば `std::atof` で `double` に変換します。入力全体の検証、範囲チェック、clamp はありません。

| 入力 | `slot_days` の結果 |
|---|---:|
| 未設定 | `7` |
| 空文字 | `0`（`atof("")`） |
| 数値として読める文字列 | `atof` が変換した値。先頭空白・符号・小数・指数を受け付け、数値の後ろに余分な文字があっても末尾までの検証はしない |
| 数値に変換できない文字列 | `0` |
| 負数 | 負の `double` のまま。最終更新からの経過日数は通常 0 以上なので、通常の slot は条件を満たさず削除対象になる |

たとえば `14days` は `14`、`junk` は `0` として扱われます。値は日数で、境界比較は `経過秒 / 86400.0 <= slot_days` です。ちょうど境界上の slot は受け入れられます。`0` や空文字では、走査時点で経過日数が 0 以下のものだけが受け入れられます。無効形式や範囲外値に対する専用エラー・警告はありません。

## 有効になる条件

- 対象は `src/dsv41/ds4_main.cpp` の `serve()`。main が `--serve` を解析した場合に `serve()` を呼びます。通常の単発生成、score、pack-info などではこの値を読みません。
- slot のディスク走査は `STRATA_DS4_SLOT_KEEP` が設定され、かつ `atoi` の結果が 0 以外で、`STRATA_DS4_SLOT_CAP` の `max(0, ...)` が 0 より大きい場合に行われます。slot が無効なら `STRATA_DS4_SLOT_DAYS` の値にかかわらず既存 slot の期限判定・削除は実行されません。
- `strata-dsv41` を直接起動したとき、`STRATA_DS4_SLOT_KEEP` は未設定なら無効です。Strata サーバーの `deepseek_slot_env()` は DeepSeek-V4.1 の子プロセスに `STRATA_DS4_SLOT_KEEP=1` を既定で与えます。`STRATA_DS4_SLOT_DAYS` 自体にサーバー側の既定値設定はありません。
- CLI 引数に日数の上書きはありません。サーバーの `child_env()` は親プロセス環境をコピーし、その後 config の `env` を重ねます。したがって親の環境値は子へ継承され、config の同名値があればそちらが優先します。

## 実行時の詳細

`serve()` の初期化時に `slot_days` を一度読みます。リクエストごとの再読込や static cache はなく、その serve プロセスの slot フォルダー初期走査で使われます。走査では `slot-*.meta` を読み、同じ stem の `.bin` があり、meta が現モデルに対応し、記録サイズと実ファイルサイズが一致し、ファイルサイズが正で、かつ `slot_age_days(meta) <= slot_days` のものを再利用候補にします。meta の更新時刻が経過日数の基準です。`.bin` ではなく `.meta` が再利用時刻の更新対象です。

条件を満たさない meta と対応する bin はその場で削除され、件数は初期化時の `NOTE sessions:` / stderr の `ds4 slots:` 通知に集計されます。通知文は「not this model's or incomplete - removed」として件数をまとめるため、期限超過だけの件数や個別ファイル名は出しません。アクセス不能などでファイル時刻を取得できない場合、`slot_age_days()` は `1e9` を返すため、通常の 7 日設定では受け入れられません。
