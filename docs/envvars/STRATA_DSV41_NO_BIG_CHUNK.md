# `STRATA_DSV41_NO_BIG_CHUNK`

調査対象: Strata `main` の HEAD `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`（2026-11-01 時点）。Strata 所有コードを対象とし、外部 DeepSeek engine の内部動作は対象外。

## 役割

DeepSeek V4.1 のセットアップが unified-memory GPU 用に起動設定へ追加する `--prefill-chunk` を抑止します。条件に合う PC では、通常は共有 pool の容量に応じて `8192` または `16384` を引数へ追加します。この環境変数を値 `1` にすると、その追加をやめ、engine に渡す設定では Strata が chunk size を指定しません。変数はセットアップ時に評価され、保存された起動設定の引数を決めます。通常の起動時にこの変数を読み直すコードは見つかりません。

根拠: `setup.py:8354-8373,8743-8750`。

## 値と判定

| 環境値 | `dsv41_prefill_chunk_args()` の結果（適用条件を満たす場合） |
|---|---|
| 未設定 | `--prefill-chunk 8192` または `--prefill-chunk 16384` を追加 |
| 空文字 | 未設定と同じ。Python の `os.environ.get(...) == "1"` は偽 |
| 文字列 `1` | 空の引数リストを返し、Strata は `--prefill-chunk` を追加しない |
| その他（例: `0`, `true`, `01`, ` 1`） | 通常どおり共有 pool に応じた引数を追加 |

文字列全体を厳密に比較し、trim、数値変換、大文字小文字変換はありません。`1anything` も `1` と一致しないため無効化しません。未設定・空文字・他の値をエラーにする処理や、この変数専用の警告・ログはありません。

## 有効になる条件

環境変数による抑止は、以下を満たす経路でだけ結果に影響します。

- DeepSeek V4.1 の `install_dsv41()` がモデル起動設定を作る経路であること（`setup.py:8492-8496,9613-9618`）。
- `cards` に `uma` が真の GPU が少なくとも 1 枚あること。
- `ram_gb + cards 内の最大 dedicated_gb` が 64 GiB 以上であること。

先の条件を満たさなければ helper は環境変数を読む前に空リストを返します。条件を満たし、値が厳密に `1` なら環境変数は chunk 引数を抑止します。値が `1` 以外なら共有 pool が 64 GiB 以上 96 GiB 未満の場合は `8192`、96 GiB 以上なら `16384` を追加します。環境変数が設定されていても、UMA GPU がない場合や pool が 64 GiB 未満の場合にはこの関数による引数追加はありません。

## 実行時の詳細

`install_dsv41()` は `dsv41_prefill_chunk_args(cards, ram)` の返り値を `--pack`、`--max-context` などとともに設定の `args` リストへ展開し、その設定を `write_setup_config()` で保存します（`setup.py:8743-8750,6648-6676`）。その後の `start()` は保存済み JSON の `args` を読み、Strata server を起動します（`setup.py:7118-7125,7148-7152`）。したがってセットアップ後に環境変数を変えても、既存設定の `args` はこの変数だけでは更新されず、再セットアップで再評価される経路です。

この名前を環境から読む本番コードは `setup.py:8371` のみです。対象名の他のソース参照は `setup.py:8360` のコメント、テスト `tests/terminal/test_dsv41_prefill_chunk.py:39`、説明資料 `docs/STRIX_HALO.md:86` です。コメントでは `1` が engine 自身の選択を残すとしています。Strix Halo 資料は 8,192 の固定例を説明していますが、現行 setup 実装は共有 pool に応じて 8,192 または 16,384 を選ぶため、資料の記述は現在の一般的な分岐を網羅しません。ここでは外部 engine が chunk 指定なしで実際に選ぶ値や、その実行時効果は断定しません。

条件不成立、値の違い、または値 `1` による抑止に対して、この環境変数固有の終了・失敗・ログ経路はありません。セットアップの通常の設定書き込みと起動処理が続きます。
