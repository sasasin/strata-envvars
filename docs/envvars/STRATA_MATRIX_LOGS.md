## 役割

これは通常の Strata 実行ファイルやサーバーの設定ではなく、端末終了経路のテスト行列 `tests/terminal/lifecycle_matrix.py` が後片付け時のログを保存するためのテスト用変数です。調査対象リポジトリでは、このファイル以外に同名変数の参照はありません。`docs/CLOSING.md` は同スクリプトをサーバー終了経路の検証手段として説明しています。

## 値と判定

| 値 | 動作 |
|---|---|
| 未設定、または空文字 | 保存しない。`os.environ.get()` は未設定時に `None`、空文字設定時に `""` を返し、どちらも `if keep` を通らない。 |
| 空でない文字列 | その文字列を `Path` に渡して保存先にする。数値変換、真偽値文字列の解釈、前後空白の除去はない。 |

相対パスの場合の基準はテストプロセスの現在の作業ディレクトリです。保存先ディレクトリを `mkdir(parents=True, exist_ok=True)` で作成し、存在する `serve.log` と `engine.log` をそれぞれ `{case名}.serve.log`、`{case名}.engine.log` の名前でバイト列のまま書き込みます。同名の保存先ファイルは上書きされます。保存先作成や書き込みの失敗はこの箇所で捕捉されません。

## 有効になる条件

`serve_case()` の終了処理で、環境変数の値が空でない場合に限り動きます。これは行列スクリプトを実行するテストプロセス自身が参照する値で、サーバーや engine の環境変数として渡す設定ではありません。保存対象のログファイルが `rig.root` に存在する場合だけ、そのファイルをコピーします。

## 実行時の詳細

値は `serve_case()` の `finally` 節でケースごとに読み取られるため、判定をモジュール初期化時にキャッシュしません。その時点で値が空でなければ、保存先を作成し、存在するログをケース名付きで保存します。その後 `rig.root/serve.log` は環境変数の設定にかかわらず空にされます。`engine.log` はここではクリアされません。
