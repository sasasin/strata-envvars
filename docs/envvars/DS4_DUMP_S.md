# `DS4_DUMP_S`

調査対象: Strata `main` の HEAD `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`（2026-11-01 時点）。調査対象リポジトリの作業ツリーは `main...origin/main` で未変更。

## 役割

DeepSeek-V4.1 エンジンのレイヤー内サブステップの値を、指定したファイルへバイナリ記録します。環境変数の値そのものは真偽値として解釈されず、ファイルパスとして `fopen(..., "wb")` に渡されます。実装は `src/dsv41/ds4_model.cu` にあり、CMake の `STRATA_BUILD_DSV41` が有効なときに作られる独立実行ファイル `strata-dsv41` 用です。この CMake オプションは既定 OFF です（`CMakeLists.txt:906-920`）。

## 値と判定

| `DS4_DUMP_S` の状態 | Strata の処理 |
|---|---|
| 未設定 | ファイルを開かず、サブステップ記録をしない。 |
| 空文字 | 空文字をパスとして `fopen` する。開けず null になれば記録しない。 |
| 空でない値 | 文字列全体をファイルパスとして `fopen(path, "wb")` に渡す。開けた場合は作成または切り詰めて書き込む。 |

数値変換、範囲判定、空白除去、大小文字比較はありません。`0` や `false` もパス文字列です。`fopen` が失敗しても戻り値が null になるだけで、このコードは警告・エラーを出しません。CLI 引数による上書きや、`DS4_DUMP_S` 以外のパス設定はありません。

## 有効になる条件

ファイルが開けても、各記録点で `DS4_DUMP_S_LAYERS` が選ぶ layer と `DS4_DUMP_S_NAMES` が選ぶ名前の両方に一致する必要があります。layer の既定値は `0,1,2,3` です。指定文字列はカンマで分割し、空要素を飛ばして各要素に `atoi` を適用します。したがって未設定なら先頭 4 layer、空文字なら対象 layer なし、無効な数値文字列は通常 `atoi` の結果 `0` となります。空白や末尾の文字も特別扱いせず、数値として読める先頭部分が使われます（`src/dsv41/ds4_model.cu:1283-1295,1447-1451`）。

`DS4_DUMP_S_NAMES` は未設定なら全記録名を通します。設定時は前後にカンマを付けた文字列に `,名前,` が含まれるかを検索するため、カンマ区切りの完全一致名で絞ります。空文字を設定すると一致する名前がなくなります。この名前フィルターは関数内 static に初回評価結果を保存します（`src/dsv41/ds4_model.cu:1453-1455`）。

CMake 上では `STRATA_BUILD_DSV41` が有効で、かつ `STRATA_HIP_GFX906` が無効な場合にこの実行ファイルを構成します。CUDA/HIP で共通の dump 判定・書き込みコードを使い、`STRATA_METAL` ビルドでは GPU 読み戻し前に Metal dispatch を flush/synchronize する分岐があります（`CMakeLists.txt:909-920`, `src/dsv41/ds4_model.cu:1457-1478`）。この環境変数にサーバーモードや CLI オプションによる別の判定はありません。

## 実行時の詳細

`DS4_DUMP_S` は `Impl` のメンバー初期化時に一度読み、ファイルを開きます。`Impl` は `Model` の構築時に作成されるため、モデルの load/feed より前に評価されます。環境をその後変更しても、このファイルハンドルや設定は再評価されません（`src/dsv41/ds4_model.cu:1280-1282,10698-10702`）。

記録は `dump_sub` / `dump_sub_host` によって行われます。GPU 上の値は device-to-host コピーと stream 同期の後に出力し、Metal ではその前に dispatch の flush と device 同期を行います。各レコードは 16 byte の名前領域（最大 15 文字をコピーし残りを NUL）、`int64` 4 個 `[layer, p0, T, nbytes]`、続けて `nbytes` の生バイト列です。レコード単位で mutex を取り、毎回 `fflush` します。`fwrite` / `fflush` の戻り値は検査されません（`src/dsv41/ds4_model.cu:1457-1478`）。

呼び出しは attention、Engram、MoE などの中間値にあります。例として、window 経路は `src/dsv41/ds4_model.cu:8116-8134,8304-8336`、layer 経路は `src/dsv41/ds4_model.cu:10040-10079,10105-10106,10530-10552,10579-10593` に記録点があります。分岐によりその計算自体が実行されない場合や、`T` / 行数条件が満たされない場合は該当記録点も呼ばれません。レイヤー内の値をコピーするため、値の読出しと同期が発生します。

ファイルを開けない場合、または layer/name filter に合わない場合、記録は静かにスキップされます。書き込みエラーも明示的なログや失敗伝播にはなりません。確認した実装にはこのファイルに関する専用 stderr/stdout メッセージや終了コード変更はありません。
