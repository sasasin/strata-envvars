# `SHOW_TEXT`

調査対象: Strata `main` の HEAD `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`（2026-11-01 時点）。

## 役割

同梱ツール `tools/dsv41/serve_prompts.py` が、生成 token を復号したテキストを `TEXT` 行として標準出力に表示するかを制御します。Strata の C++ エンジン本体の生成処理を切り替える変数ではなく、この Python のプロンプト比較ツールで使われます。スクリプトの説明では、エンジンを `--serve` で起動し、各プロンプトを送信して参照 token 列との一致を比較するツールです（`tools/dsv41/serve_prompts.py:2-5,27-33`）。

## 値と判定

| `SHOW_TEXT` の状態 | テキスト表示 |
|---|---|
| 未設定 | 通常プロンプトでは表示しない |
| 空文字 | 通常プロンプトでは表示しない |
| 空でない文字列 | 通常プロンプトでは表示する。`0`、`false` なども表示する |
| JSON プロンプトの `pic` が真 | `SHOW_TEXT` の状態にかかわらず表示する |

実装は `os.environ.get("SHOW_TEXT")` の戻り値を `or` 条件で使います。未設定は `None`、空文字は falsy、それ以外の文字列は truthy です。数値変換、文字列比較、許容値検査、境界処理はありません。設定済みでも空文字は通常プロンプトの表示を有効にしません（`tools/dsv41/serve_prompts.py:63-65`）。

## 有効になる条件

この変数を読むのは `tools/dsv41/serve_prompts.py` だけです。対象スクリプトを実行して通常プロンプトを処理する場合、空でない値で追加表示が有効になります。JSON の `pic` フィールドが真のプロンプトでは、同じ表示が常に有効です。

スクリプトは `--` より前の引数をプロンプト ID の絞り込みに使い、`--` より後の引数をエンジンコマンドとして `--serve` を付加して起動します。この引数処理に `SHOW_TEXT` 用の CLI オプションはありません（`tools/dsv41/serve_prompts.py:27-33`）。CUDA/HIP などの backend、OS、モデル状態による `SHOW_TEXT` の条件分岐はこの読み取り箇所にはありません。

## 実行時の詳細

スクリプトは各プロンプトの生成応答を読み終えて `DONE` を受け取った後、`SHOW_TEXT` を評価します。有効なら生成 token `gen` を `detok()` で復号し、`print("TEXT", repr(...), flush=True)` で標準出力へ出します。その後に参照 token との prefix 比較、集計行の出力、結果 JSON の更新を行います（`tools/dsv41/serve_prompts.py:44-65,67-80`）。

値はモジュール読み込み時にキャッシュされず、プロンプトごとの表示判定時に環境から読み直されます。スクリプト自身が環境変数を変更する処理はありません。表示を無効にしたときに `TEXT` 行を出さない以外の警告・エラー・終了経路は、この条件分岐にはありません。リポジトリ全体の `SHOW_TEXT` 完全一致検索で確認できた環境変数参照もこの 1 箇所です。エンジン起動コードに `env=` による環境の上書きはなく、この変数をエンジン側が読む箇所は見つかりませんでした。
