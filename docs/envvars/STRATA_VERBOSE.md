## 役割

DeepSeek-V4.1 のセットアップで専用エンジン `strata-dsv41` が見つからず、インストールを停止する場合に、開発者向けのビルド方法を追加表示するための診断用スイッチです。エンジンの探索・取得や対応 GPU の判定を変えず、エラー時に出る補足一行だけを制御します。

| 値 | この変数による補足表示 |
|---|---|
| 未設定 | しない |
| 空文字 | しない |
| `1` | する |
| その他（例: `0`, `true`, `01`, ` 1`） | しない |

## 有効になる条件

`STRATA_VERBOSE=1` でも、DeepSeek-V4.1 のセットアップ経路でエンジン実行ファイルが最終的に `None` の場合に限り表示されます。既存エンジンが見つかる、または取得できる場合、この変数による表示はありません。GitHub に接続できず、既存エンジンも保留中のパッケージもない場合は、この分岐より前に別の `fail()` で停止するため、開発者向け一行は表示されません（`setup.py:8041-8058`）。

同じ条件式には `--verbose` が `sys.argv` に含まれる場合もあります。ただし環境変数の判定は引数とは独立しており、`setup.py` の引数パーサーには `--verbose` の登録がありません（`setup.py:8420-8424` 以降の引数定義）。
