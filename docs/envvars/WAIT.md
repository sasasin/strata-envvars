# `WAIT`

調査対象: Strata `main` の HEAD `ffa80d73133ea5c548aefe57889a16e8085a938f`（2026-11-03 時点）。

## 役割

`WAIT` は `docker/smoke-test.sh` 専用の待ち時間上限（秒）です。初回起動後に `/v1/models` が応答するまでの待機と、`RESTART=1` のときの再起動後の待機に使われます。Strata エンジンやサーバーが読む設定ではなく、このスクリプト自体が環境から取り込みます（`docker/smoke-test.sh:13,33-43,94-102`）。

## 値と判定

| 環境値 | スクリプト内の値 | 挙動 |
|---|---|---|
| 未設定 | `2400` | 2400 秒を上限として使う |
| 空文字 | `2400` | `${WAIT:-2400}` の `:-` により既定値を使う |
| 空でない値 | その文字列のまま | 数値への変換、形式検証、clamp はしない。後続の整数比較にそのまま渡す |

初回の待機では、経過秒 `el` が `WAIT` より大きいかを Bash の `[` `-gt` で比較します。境界は `>` なので等しい間は timeout せず、ループ内の HTTP 要求（最大 5 秒）と 10 秒の sleep を挟んで次の判定に進みます。負数や `0` も補正されず、負数なら最初の比較で timeout 条件を満たし、`0` でも経過時間が 0 秒を超えた判定で timeout します（`docker/smoke-test.sh:35-43`）。

整数でない値や算術式などの入力形式はスクリプトで検証されません。初回待機では `[` の整数比較に直接使われるため、不正な値に対する `WAIT` 固有の fallback はありません。再起動時は同じ値を Bash の算術式中の比較に用います（`docker/smoke-test.sh:97-102`）。したがって、任意の文字列が一貫して秒数として扱われる保証はありません。

## 有効になる条件

- `WAIT` は `docker/smoke-test.sh` を実行した場合だけ参照されます。OS / GPU backend / build macro / モデル状態による Strata エンジン内の有効条件はありません。
- 初回起動待ちは常に実行します。再起動待ちは `RESTART` が文字列 `1` の場合だけ実行され、その他の値ではスキップされます（未設定時の `RESTART` 既定値も `1`、`docker/smoke-test.sh:94-102`）。
- CLI 引数や別の設定が `WAIT` を上書きする処理はありません。`WAIT` の値はコンテナ起動時の `docker run` に渡されず、ローカルの smoke-test スクリプト内だけで使われます（`docker/smoke-test.sh:27-30,33-43`）。

## 実行時の詳細

スクリプト開始時に `WAIT` を一度シェル変数へ代入します。実行中に親プロセスの環境を変更しても、この代入済みの値は再評価されません（`docker/smoke-test.sh:10-14`）。

初回起動では、コンテナが `exited` または `dead` なら `FAIL: container ended before serving` とコンテナログ末尾 60 行を出して終了コード 1 で終わります。HTTP 200 が上限判定より先に得られれば待機を抜けます。経過秒が上限を超えると `FAIL: not serving after ...s` とログ末尾 60 行を出して終了コード 1 で終わります（`docker/smoke-test.sh:35-44`）。

再起動の待機は `RESTART=1` のときだけ行います。経過秒が上限を超えると `bad` が失敗フラグを立ててループを抜け、その後も残りのスクリプトを進めます。最後の `RESULT` 表示と `exit $fail` により最終終了コードは 1 になります（`docker/smoke-test.sh:20-22,94-108`）。

## 根拠

- `docker/smoke-test.sh:10-14` — 未設定・空文字の既定値、スクリプト開始時の代入。
- `docker/smoke-test.sh:18-23` — `bad` が失敗フラグを設定し、出力をログへ記録する準備。
- `docker/smoke-test.sh:33-45` — 初回起動の HTTP health check、比較境界、timeout 時のログと終了。
- `docker/smoke-test.sh:94-108` — 再起動条件、再起動待ち、最終結果と終了コード。
