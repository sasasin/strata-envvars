# `STRATA_DRAFT_COSTS_DIR`

調査対象: Strata `main` の HEAD `c77572806996349b49995e4f98d41b5294d36a21`（`2026-11-17` 時点）。

## 役割

`serve/server.py` がエンジン起動引数 `--draft-costs` 用のコスト表ファイルの保存先ディレクトリを選ぶときに使う。環境変数自体がコスト表機能を有効化するわけではなく、有効と判断されたときの保存先だけを置き換える。未設定または空文字なら、プロファイル設定ディレクトリの隣にある `draft-costs` を使う。 (`serve/server.py:4108-4116`)

## 値と判定

サーバープロセスの Python `os.environ.get` で文字列を読み、真偽値だけで分岐する。空文字は未設定と同じフォールバックになる。空でない文字列は内容を検証せず `Path(...).expanduser()` に渡すため、空白や `0` を含む文字列もパスとして採用される。数値変換、大小文字比較、範囲制限はない。 (`serve/server.py:4108-4116`)

| 条件 | 未設定 | 設定時に使われる値 | フォールバックする値 |
|---|---|---|---|
| 全 OS | 既定ディレクトリを使用 | 空文字以外。先頭の `~` は `expanduser()` の対象 | 空文字。例: `""` |

`"0"`、`"false"`、空白だけの文字列も空でないためパスとして使う。相対パスを絶対パスに解決する処理やディレクトリ作成・存在確認は、この選択関数にはない。パスを使った実際のファイル操作はエンジンに渡した後の処理であり、ここではその挙動を断定しない。 (`serve/server.py:4112-4116`)

環境変数が未設定または空の場合、保存先は `strata_control.profiles.profile_dir().parent / "draft-costs"`。`profile_dir()` は `STRATA_PROFILE_DIR` が非空ならその展開後パスを使い、そうでなければ Windows では `%APPDATA%\Strata\profiles`（`APPDATA` 未設定時はホームの `AppData/Roaming/Strata/profiles`）、他 OS では `$XDG_CONFIG_HOME/strata/profiles`（未設定時は `~/.config/strata/profiles`）を返す。したがって、例えば `STRATA_PROFILE_DIR` が指定されていればその親ディレクトリの `draft-costs` が既定先となる。 (`strata_control/profiles.py:38-45`; `serve/server.py:4115-4116`)

## 有効になる条件

- この変数は、サーバーが `draft_costs_args()` で `--draft-costs` 引数を追加する場合にだけ参照される。設定値があっても、それ自体で機能を有効化しない。 (`serve/server.py:4119-4135`)
- 設定ファイルの `draft_costs` が明示されていれば、その値が使われる。値が Python の `True` でなければ引数追加を行わない。キーがなければサーバー import 時に決まる既定値を使い、現行コードでは `sys.platform == "darwin"` の場合だけ既定で有効。設定で `draft_costs: true` とすれば他 OS でも有効にできる。 (`serve/server.py:4077-4087`, `4119-4128`)
- すでに引数に `--draft-costs` があればその引数を保ち、環境変数から保存先を作らない。 (`serve/server.py:4125-4128`)
- エンジン実行ファイルに `--draft-costs` の文字列が見つからない場合は、設定ファイルで有効を明示していても追加しない。設定で有効を明示しておらず、実行ファイルが指定されない・読めないなど対応状況を確認できない場合も追加しない。 (`serve/server.py:4091-4105`, `4129-4132`)
- 上流の引数組み立てで `draft_layer.is_off(cfg)` が真かつ `decision.flags` がない場合、draft layer 関連引数を除去してから `draft_costs_args()` に進む。ただしコスト表引数の追加条件自体は `draft_costs` の設定と既存引数、エンジン対応判定で決まる。 (`serve/server.py:3934-3940`, `3965-3967`, `4125-4132`)

## 実行時の詳細

`engine_args()` が引数を組み立てるたびに `draft_costs_args()` へ進み、条件を満たしたとき `draft_costs_dir()` が `os.environ` を直接読む。ディレクトリ値は関数内にキャッシュされないため、呼び出し時点のサーバープロセス環境が評価される。通常のエンジン起動では、その結果を `<ディレクトリ>/<モデル名>-<引数ハッシュ>.costs` として `--draft-costs` の値に追加し、`StrataEngine` に渡す。 (`serve/server.py:3882-3884`, `3965-3967`, `4108-4135`, `9514-9522`)

サーバーは保存先ディレクトリをここで検証・作成せず、環境変数の値を別の環境変数として子プロセスへ転送もしない。パスはコマンドライン引数の一部として渡される。`STRATA_DRAFT_COSTS_DIR` を設定していても、前節の条件で `--draft-costs` が追加されなければ使用されない。 (`serve/server.py:4112-4135`, `9514-9522`)
