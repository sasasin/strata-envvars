# `MMB_ONLY`

調査対象: Strata `main` の HEAD `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`（2026-11-01 時点）。

## 役割

Apple Metal 用の単体行列ベンチマーク `mm_bench` が実行するカーネル名を部分文字列で絞り込みます。これは `metal/tests/mm_bench.cpp` のベンチツールに限った設定であり、通常の Strata CLI / 推論実行経路からは参照されません。Metal CMake プロジェクトは `metal/tests/*.cpp` をファイル名ごとの実行ファイルとして生成するため、このソースは `mm_bench` ターゲットになります（`metal/CMakeLists.txt:41-48`）。

## 値と判定

| 値 | 判定と結果 |
|---|---|
| 未設定 | 全カーネルを実行する。 |
| 空文字 | 空文字列はすべてのカーネル名に含まれるため、全カーネルを実行する。 |
| 空でない文字列 | カーネル名にその文字列が含まれるものだけ実行する。大文字小文字を区別する部分文字列検索で、数値変換や値の検証はしない。 |
| 一致する名前がない文字列 | ループ内のカーネルをすべて飛ばす。エラー扱いにはならず、最後に `0` を返す。 |

各カーネルは固定リスト `ks` にあり、選択条件は `k.name.find(only) == std::string::npos` ならスキップ、というものです。したがって、たとえば `half` は名前に `half` を含むカーネルを選び、`HALF` は一致しません（`metal/tests/mm_bench.cpp:36-50,62-65`）。

## 有効になる条件

`MMB_ONLY` は `mm_bench` を実行した場合だけ参照されます。Metal CMake プロジェクト自体が Apple 以外では構成を停止するため、この同梱ツールのビルド対象は macOS です（`metal/CMakeLists.txt:13-18,41-48`）。通常の Strata エンジンや他 backend の実行に同じ変数名の読み取り箇所はありません。

## 実行時の詳細

`main()` は Metal context の作成、device 情報の表示、カーネルライブラリのコンパイル、バッファ確保を行った後、カーネル反復の直前に `std::getenv("MMB_ONLY")` を一度呼びます。その値を `only` に保持し、固定リストの各カーネル名との部分文字列比較に使います。ループ中の再読み取りやキャッシュ機構はなく、起動後の環境変更はこの選択に反映されません。CLI 引数や他の環境変数による上書きもありません（`metal/tests/mm_bench.cpp:20-25,36-65`）。

選ばれたカーネルごとに、小さい積の CPU 参照との相対誤差を標準出力へ出し、その後、形状ごとの時間と TFLOP/s を表示します。未設定または空文字なら全カーネルについてこれを行います。一致なしの場合も context 作成・コンパイル・バッファ確保・device 表示までは行いますが、カーネル処理を行わず `0` で終了します。`MMB_ONLY` に関する警告やエラー出力は実装されていません（`metal/tests/mm_bench.cpp:20-25,61-115`）。
