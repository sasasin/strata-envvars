# `STRATA_ENGINE_STALL_S`

調査対象: Strata `main` の HEAD `011c9e600a93bbc9fd451c563501b5831c32bbca`（2026-10-22 時点）。対象は Strata のサーバー実装であり、外部ライブラリ内部の動作は含めない。

## 役割

`serve/server.py` が、出力のない engine を「停止している」と判定する時間を秒単位で指定します。既定値は90秒です。engine がその間ずっと無出力で、プロセスの CPU 使用時間・I/O バイト数がほぼ増えず、GPU 使用中とも観測されない場合、サーバーは engine を終了し、そのリクエストをエラーにします。無出力でも処理中と観測される場合は終了せず、ログを一度出して通常の `engine_silence_s` 制限に任せます。

この値は、並列リクエストが空き slot を待つ時間の診断にも使われます。その場合は待機がこの秒数を超えると状況を一度ログに出しますが、この変数によって待機中リクエストや engine を終了するわけではありません。

## 値と判定

モジュール読み込み時に共通 helper `_timeout_env()` が `float(os.environ.get(...))` で変換します。`float()` が受け付ける数値文字列を使い、文字列全体を数値として変換します。

| 値 | 扱い |
|---|---|
| 未設定 | 既定の `90.0` 秒 |
| 空文字、または `float()` が変換できない文字列 | `ValueError` を捕捉し、既定の `90.0` 秒 |
| 0 または負数 | helper が `None` を返す。後段では 0 秒相当となり、停止監視と slot 待機ログの期限判定を無効にする |
| 正の数 | その秒数を監視間隔として使う。小数も可 |
| `nan` / `inf` など | Python の `float()` が変換するため受け入れられ、有限値チェックはない。通常の有限秒数としての動作は保証されない |

空白を含む数値などの受理規則も Python の `float()` に従います。`engine_silence_s` はモデル設定から読む別の制限であり、この環境変数がその値を変更することはありません。

## 有効になる条件

- `serve/server.py` のサーバープロセスで有効です。環境変数はモジュール読み込み時に一度評価され、同じプロセスで後から環境を書き換えても反映されません。
- リクエスト処理中の停止判定は、engine から最後に行を受け取ってから監視します。`psutil` で engine 子プロセスの CPU 時間と読み書きバイト数を取得できなければ、この判定では engine を終了しません。セットアップの依存一覧には `psutil` が含まれます。
- GPU 使用中の判定関数が接続されていて真を返す場合、CPU/I/O の増分が小さくても停止とは判定しません。GPU telemetry が例外を出した場合は、この判定に限って GPU 使用中を `False` として扱います。
- `STRATA_ENGINE_STALL_S` を0以下にすると、この停止監視が無効になります。別の `engine_silence_s` による無出力制限は独立して残ります。
- バッチの slot 待ちでは、設定値を超えても警告ログを一度出すだけです。待ち時間そのものには、別途 queue deadline がある場合にそちらが適用されます。

## 実行時の詳細

通常の生成経路では、最後に受信した engine 出力からの経過時間を監視し、まず `psutil` による CPU/I/O の基準値を取ります。設定時間以上無出力となった後に再計測し、監視期間中の CPU 増加が0.5秒以下、I/O増加が1 MiB以下で、かつ GPU telemetry が使用中を示さなければ停止と判断します。engine が無出力中も動いているなら、その時点を新しい比較基準として次の監視時間を設け、標準出力に `[strata] the engine has said nothing for ... but is still working; it is not ended ...` を一度出します。engine が停止と判断されると、サーバーは子プロセスを kill し、`EngineSilent` エラーを返します。次のリクエストでは終了済み engine の再起動経路に入ります。

監視は0.5秒以下の queue poll ごとに呼ばれます。engine から何らかの行を受信すると、無出力時間の基準と監視状態をリセットします。`STRATA_ENGINE_STALL_S` の値はサーバーから engine プロセスへ渡す設定として実装されていません。
